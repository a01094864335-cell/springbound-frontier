# 전투 UI 전체 목업 · Study 01

`index.html`을 브라우저로 열면 30개 전투 상태를 한 장씩 보거나 전체 펼쳐서 비교할 수 있습니다. 인쇄 / PDF는 전체 30개 화면을 인쇄용으로 전환합니다. 외부 라이브러리·네트워크 없이 로컬 파일로 열립니다. `?screen=5`는 여섯 번째 화면, `?view=all`은 전체 보기입니다.

## 디자인 기준
- 1280 × 720, 필드를 우선하는 작은 상태창과 세로 명령창.
- 짙은 청회색 바탕, 이중 은빛 테두리, 옅은 금색 선택 표시.
- 아군 상태는 왼쪽 아래, 대상 상태는 오른쪽 위, 명령은 오른쪽 아래.
- 필드에는 현재 위치·대상·이동 경로·선택 칸·공격 예고를 분리.
- 목록과 확인창은 중앙, 대화는 하단. 시스템 창에서는 필드를 어둡게 처리.

## 범위
기본 전투, 명령과 대상 선택, 이동 불가와 빗나감 등 예외, 아이템 목록·대상·예약, 기술·마법 목록·범위·시전, 동료·능력치·적 정보·상태 이상, 전투 대화·안내, 승리·패배·재도전, 표시 설정·키 설정·후퇴·종료 확인을 포함합니다. 상세 목록은 `screens.json`에 있습니다.

마법·동료·상태 이상·후퇴 등 확장 화면은 기능 구현이 아니라 디자인 시안입니다. 피해량·시간·능력치·키 배치·설정 목록은 원작 PC판과 동일하다고 검증한 내용이 아닙니다. 현재 자체 게임 필드와 캐릭터만 사용하며 원작 이미지를 포함하지 않습니다.
