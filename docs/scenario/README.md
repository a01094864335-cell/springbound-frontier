## 기존 자료와의 우선순위

[확정 기획](../confirmed-design.md), [인물 설정](../characters.md), [기존 프롤로그 원고](../prologue-dialogue.md), [전투·장비 규칙](../combat-equipment-and-motion-spec.md)을 함께 읽는다. 본 초안의 시설 작동 방식과 세부 사건은 새 제안이며, 확정 기획과 충돌하면 구현 전에 해당 항목을 검토한다. 기존 대화 데이터와 게임 코드는 이번 문서 작업으로 변경하지 않는다.

## 프롤로그 연결

- MQ01: 기존 마르타 아침 → 물 긷기·여관 심부름(두 개 순서 자유) → 집에서 약 준비를 재사용한다. 심부름 순서에 따른 기존 재대화 상태를 유지한다.
- MQ02: 기존 산길 이동·`leon_first`를 활용한다. 부상 원인 설명은 확인된 사실까지만 한다.
- MQ03: `leon_first`와 `leon_bridge` 사이에 추가할 신규 튜토리얼. 레온은 움직이거나 싸우지 못한다. 검 대여 → 에일의 두려움 → 거리/이동 → 공격 조작 → 승리 → 검을 내리는 장면 순서다. 대사는 조작을 완료했을 때 다음 단계로 넘어가며, 조작 키는 실제 입력 설정을 표시한다.
- MQ04: 기존 응급 처치 장면을 전투 뒤에 연결한다. 산길에서 완치시키지 않는다. 레온 동행은 부상에 맞춰 천천히 이동하는 연출로 처리한다.
- MQ05: 기존 돌샘 약 전달·에다·차·귀향 선택 장면을 재사용하되 귀환 기록 열람을 보강한다. MQ06에서 고향에 먼저 돌아온 뒤 큰 여정에 나선다.
- 첫 검의 대여가 ‘모든 무기를 쓰는 주인공’ 설정을 변경하지 않는다. 방패는 지급·착용 가능한 상태에서만 보인다. 방패 없는 첫 튜토리얼에 방패 필수 조작을 넣지 않는다.
- 레온의 전투 합류는 치료 뒤인 교량 장 시작 전으로 잡되, 에다의 회복 판정과 경과 시간 장면을 추가한다. 부상 직후 다음 전투에 바로 투입하지 않는다.

## 장면·플레이 구현 지침

각 퀘스트는 목표 수신 → 조사/이동/전투 → 완료 확인 → 다음 행동 합의로 구성한다. 발췌 대사 사이에는 이동·표정·정보 확인·선택에 따른 짧은 반응을 추가해야 한다. 생략 구간을 대사 파일의 누락으로 오해하지 않는다.

탐험은 에일 한 명을 조작한다. 전투는 기존 확정 기획의 최대 4인 편성과 동료 지시를 따른다. 공동 작전의 다른 지역은 별도 플레이어블 주인공으로 전환하지 않고 수신 보고·짧은 현장 컷으로 보여준다. 동료가 다섯 명이어도 한 전투에 여섯 명을 동시에 배치하지 않는다. 중추에 함께 있는 비출전 인물은 조사·연락 담당으로 배치한다.

MQ13은 호위 대상 안전 확보와 아군 철수가 승리 조건이다. 무한 증원 전멸을 요구하지 않는다. MQ41은 전환 저지·유지·현장 완료 확인의 세 단계다. 실제 턴/시간·적 수·난이도는 전투 설계에서 확정한다. 실패 시 직전 단계 재시도나 체크포인트 복귀를 제공하고 필수 증언·물자를 영구 삭제하지 않는다. 단순 대화 선택으로 메인 진행을 막지 않는다.

MQ35의 각 지역 준비는 필수 메인 단계다. 선택 서브 이벤트 완료 여부와 무관하게 기본 수송·구호·연락 인력을 확보한다. 동료가 관련 개인 이벤트를 하지 않았어도 MQ41의 역할 수행에 필요한 본편 대화는 제공한다.

정보 공개 선택은 공개/익명 공개/보호된 보관의 차이다. 핵심 증거 자체를 폐기하는 선택은 제공하지 않는다. 선택의 태도 차이는 다음 대화의 반응에 반영하고 조사 결과를 임의로 바꾸지 않는다.

## 서브 이벤트 운영

동료 6계열 각 3편과 생활 NPC 6편으로 총 24편이다. 해금은 해당 MQ 완료 후, 선행 이벤트는 선택 서사의 연속성을 위한 조건이다. 메인 진행 조건에는 들어가지 않는다. 대부분 거점 재방문 또는 후반 통합 구호 거점에서 진행할 수 있다. 기간 한정 두 장면은 출발 전 명시적으로 알린다. 놓친 장면의 요약은 연애·완료 보상을 소급 지급하는 대체 클리어가 아니다.

MQ42 해금 이벤트는 엔딩의 선택 가능한 후일담 장면이다. 자유로운 엔딩 후 탐험 시스템을 새로 요구하지 않는다. 후일담을 닫기 전에 미관람 장면을 선택하고, 엔딩 감상 목록에서 이미 해금한 장면을 다시 볼 수 있게 설계한다.

## 수정과 검증

JSON을 편집한 뒤 저장소 루트에서 `python tools/build_scenario_docs.py`를 실행한다. Markdown은 자동 생성되므로 대사·퀘스트 수정은 JSON에 한다. 검증은 참조·선행·기간 조건의 구조를 확인하며 이야기의 재미나 실제 런타임 동작을 보증하지 않는다. 게임 테스트는 이번 변경 범위에 포함되지 않는다.
