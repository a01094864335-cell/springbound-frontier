# 프롤로그 외부 로컬 구현 명세

## 목적과 경계

집의 아침부터 돌샘에서 귀향을 결정하는 MQ01~05를 하나의 플레이 구간으로 연결한다. 이 문서는 **다른 로컬의 구현 담당자를 위한 명세**다. 현재 작업에서는 게임 코드·입력 설정·대화 런타임·에셋을 변경하거나 Godot를 실행하지 않는다.

사용자 확정 규칙은 [확정 기획](../../confirmed-design.md)을 우선한다. 이 문서의 상태 이름·단계 구분·화면 문구는 구현 제안이며 기존 코드에 해당 이름이 이미 존재한다는 뜻이 아니다. 수치 밸런스·세이브 형식 버전·슬롯 정책·미정 사운드 파일을 임의로 확정하지 않는다.

## 읽는 순서와 전달물

1. [전체 대본 52장면](full-script.md): 필수 26장면(선택 A/B 별도 포함), 재도전·보충 2장면, 선택·재대화 24장면. 대사·서술·UI·선택 문구 합계 331개 항목.
2. 아래 연결표와 상태 규칙.
3. [외부 로컬 완료 기준과 검수표](acceptance.md).
4. [장면 원본 JSON](scene-source.json): 문서 편집·리뷰용. 런타임의 기존 대화 JSON 스키마와 다르므로 그대로 복사하지 않는다.

이전 [메인 퀘스트 발췌](../main-scenario.md)의 MQ01~05는 요약이다. 해당 구간의 구현 대사는 이 전체 대본을 기준으로 하고, 상위 세계관·후속 목적은 [이야기 규칙](../story-bible.md)을 따른다. 전체 원고가 승인되기 전에는 이 대본도 제작 초안으로 취급한다.

심부름 결과, 배달 수락, 꾸러미 확보, 출발 인사는 서로 다른 상태다. ‘약을 갖고 있다’만으로 미완료 심부름을 건너뛰는 것은 신규 진행에서 허용하지 않는다. 과거 저장 이관은 아래 예외로 처리한다.

## 전투와 조작 계약

- 탐험하던 산길 맵에서 그대로 전투를 시작한다. 위치 재배치는 장애물·도달 불가 문제를 피하기 위한 최소 안전 배치로 제한하며 별도 투기장 맵으로 보내지 않는다.
- 첫 전투의 조작 대상은 에일 하나다. 레온은 상처 입은 비전투 NPC로서 AI 공격·피격 유인·자동 회복·플레이어 선택 대상에서 제외한다. 레온이 쓰러져 패배하는 추가 호위 규칙은 넣지 않는다.
- 적은 약한 마물 한 마리다. 이름·종·스탯은 기존 몬스터 자료와 실제 밸런스 검토로 선정한다. 이 명세는 새 몬스터 외형 제작을 요구하지 않는다.
- 전투 시간은 명령 선택 중 정지, 실행 시 재개한다. Space는 확정된 기본 정지/재개 키지만 대본에는 바인딩 이름을 치환한다. 탐험 이동은 WASD, 전투 이동·대상 선택은 마우스 중심이다. 대화 진행 Space와 전투 재개 Space가 한 번의 입력으로 연속 발생하지 않게 입력 해제 경계를 둔다.
- 대기는 현재 행동을 중단하고 자리를 지키는 명령이다. 무적·방어력 증가·자동 공격을 새로 붙이지 않는다. 대기 시전의 판정 시점을 구현에서 한 가지로 통일한다.
- 회피는 표시된 위험 범위 밖으로 이동하는 것이다. 별도 회피 키나 구르기 무적 시스템을 추가하지 않는다. 공격 예고는 첫 마물 패턴의 가독성 안내이며 모든 적 공격이 반드시 예고 범위를 가진다는 전체 규칙으로 확대하지 않는다.
- P10~P11의 입력 학습 중에는 적의 공격 실행을 보류한다. P12는 정지 중 이동을 고른 다음 재개하면 실제 공격이 나온다. 잘못 피하면 실제 피해를 받으며 R02로 다시 안내한다. 타격 피해를 받은 뒤 서술상 성공한 것처럼 덮지 않는다.
- P13의 첫 유효 타격 전 적이 쓰러져 필수 설명이 건너뛰어지지 않도록 첫 전투 스탯·단계 배치를 검토한다. 전투 중 적을 억지로 부활시키거나 임의로 HP를 되돌리지 않는다. 재도전 때도 처음부터 격파 가능한 정상 전투 규칙을 사용한다.
- P14는 개인 회복품 사용 가능성을 설명할 뿐 사용을 완료 조건으로 삼지 않는다. 품목·효과·초기 소지량은 별도 승인한 아이템 기획에서 가져온다. 개인 회복품이 0개이면 ‘보유 없음’을 표시하고 배달 약을 대신 열지 않는다.
- 빌린 검은 임시 장비다. 에일의 직업·전문화를 검사로 고정하지 않는다. 첫 전투는 방패 지급 전이므로 방패 필수 조작과 방패가 보이는 모션을 요구하지 않는다.
- 첫 승리 연출은 검끝을 내리고 긴장을 푸는 장면이다. 이후의 성숙한 승리 세리모니와 같은 동작을 재사용해 익숙한 전사처럼 보이지 않게 한다.

## 튜토리얼 종료·재도전

첫 안내는 정지/재개→이동→대기→범위 회피→일반 공격→선택적 회복품 순서다. ‘안내 창을 닫았다’와 ‘해당 조작을 실행했다’를 구분한다. 메뉴를 열거나 대화 기록을 보았다고 단계가 진행되지 않는다. 접근 불가능한 이동 지점을 정답으로 지정하지 않는다.

패배하면 전투 직전 HP·MP·위치·진행 상태로 복귀하고 전투 중 보상은 폐기한다. **소비한 아이템은 돌려주지 않는다.** 전투 직전 보관본을 읽을 때마다 기존 수량을 복구하는 방식은 금지한다. 같은 재도전 세션에서 남은 수량과 소비 이력을 유지하며, 아이템 사용 애니메이션의 반복·창 재열기로 중복 소비되지 않게 한다. 일반 수동 저장을 어디까지 되돌릴 수 있는지 같은 전역 저장 정책은 여기서 새로 정하지 않는다.

‘다시 도전’은 P08~P09의 긴 대화를 반복하지 않는다. 완료한 조작 안내의 창도 생략하되 전투 기능은 모두 열려 있다. ‘안내 다시 보기’는 P10부터 학습 단계를 다시 제공한다. 둘 다 같은 소비 내역과 전투 직전 상태를 사용한다. 재도전 안내는 필수로 회복품을 쓰게 하지 않으므로, 보유량이 0이어도 이동과 공격으로 끝낼 수 있는 난이도를 검증한다.

전투 후 HP·MP는 유지한다. P16의 붕대는 레온의 이야기상 처치이며 에일 전투 수치를 리셋하지 않는다. 차·밤 경과를 통한 회복도 기존 숙소/회복 규칙으로 명시적으로 처리하며 ‘차를 마셨으니 전원 완전 회복’을 숨겨 넣지 않는다.

## 상태와 저장 설계 제안

아래 이름은 문서상의 의미 이름이다. 기존 프로퍼티와 일대일로 일치시키거나 이름을 유지할 필요는 없지만 의미는 보존한다.

| 의미 상태 | 변경 시점 | 재진입 처리 |
|---|---|---|
| 아침/물/수건 완료 | 각 장면 마지막 페이지 닫기 | 해당 짧은 재대화로 전환 |
| 배달 수락/약 확보/출발 인사 | P04/P05/P06 종료 | 이미 완료한 지급·소비 실행 금지 |
| 레온 발견/검 대여 | P08/P09 종료 | 전투 전 단계와 재도전 상태를 별개로 유지 |
| 튜토리얼 학습 단계 | 실제 정지·이동·대기·회피·타격 조건 달성 | 완료한 안내를 다시 강제하지 않음 |
| 전투 직전 보관본/소비 이력 | 첫 전투 시작/아이템 실제 사용 | 재도전 시 소비량까지 초기화하지 않음 |
| 첫 전투 승리 | 승리 판정 한 번 | 적 재등장·승리 중복 지급 방지 |
| 레온 처치/비전투 동행 | P16/P17 종료 | 부상 상태와 동행 위치 재구성 |
| 돌샘 도착/약 인계/환자 인계 | P19/P20 종료 | 약 전달만으로 환자 인계를 생략하지 않음 |
| 차/기록 확인/귀향 태도 | P21/P22/P23A 또는 B 종료 | 미선택 분기를 같이 실행하지 않음 |
| MQ05 완료/MQ06 준비 | P24 종료 | 안전 지점 로드, 후속 맵 미구현 시 안내 |

퀘스트 진전과 지급·제거·소비는 장면을 보여주는 것과 분리한다. 대화 로그 재열람·스킵·한 페이지 뒤로 보기·장면 재진입으로 부작용이 다시 실행되지 않아야 한다. 마지막 페이지를 닫을 때 완료되는 기존 방식에 맞추되, 판정과 저장 실패를 한 번의 논리 작업으로 처리한다. 저장 실패 시 사용자가 ‘저장됨’으로 오인하지 않게 알린다.

자유 저장은 전투 밖에서 제공한다. 기존 구현처럼 대화 중 저장/불러오기는 막고 이유를 표시한다. 자동 저장은 각 퀘스트 경계와 전투 직전 보관 정책을 따라 마련하되 슬롯 수·덮어쓰기 정책은 별도 확정한다. P23에서 선택 도중 닫거나 종료해도 미선택 선택지를 확정하지 않는다.

### 기존 v1/v2 저장과의 관계

기존 [프롤로그 원고의 이관 설명](../../prologue-dialogue.md)에 따라 출발·배달까지 간 기록에 심부름을 다시 강제하지 않는다. 신규 세부 플래그가 없는 옛 저장을 ‘첫 전투 미완료’로 단순 해석해서 이미 동행·배달한 플레이어를 전투로 되돌리지 않는다.

- 발견 전 기록: 현재 위치와 준비 상태에 맞는 신규 진행으로 연결한다.
- 옛 임시 처치 후 동행 기록: 그 지점 이후를 유지하고 신규 첫 전투는 ‘이전 진행에서 생략됨’으로 구분한다. 승리했다고 거짓 회상하거나 승리 보상을 소급 지급하지 않는다. 전체 새 프롤로그 감상은 새 여정에서 제공한다.
- 옛 돌샘 인계/차 완료 기록: 완료 상태를 유지하고 아직 없는 P22~P24로 이어갈 수 있는지 검토한다. 이미 고향으로 돌아간 저장은 강제로 돌샘으로 이동시키지 않고 후속 장 접점에서 기록 확인 요약을 제공한다. 그 요약은 이 문서의 신규 본편 경로가 아니라 이관 보충 원고를 별도로 검토해야 하는 예외다.
- 손상·미지원 저장: 진행을 임의로 덮어쓰지 않고 오류를 설명한다. 기존 원본 보관과 이관 전후 비교를 외부 로컬에서 수행한다.

정확한 저장 형식 확장은 구현 담당자가 기존 구조를 확인한 뒤 제안한다. 이번 문서에서 저장 버전을 임의로 올리지 않는다.

## 기존 원고의 유지·대체 범위

| 기존 장면 | 처리 |
|---|---|
| opening, well_first, inn_first, request, medicine, farewell | 전체 대본에 재수록. 자유 순서·재대화 유지 |
| leon_first | P08로 대체. 처치 완료 전 위협 등장 |
| leon_bridge | P16~P17로 분해·대체. 전투 후 처치와 동행 합의 |
| leon_again, leon_arrival, delivery, closing | P18~P21로 재사용. 앞뒤 전투·기록 장면 연결 |
| halven, eda 및 기타 재대화 | 선택 부록 재수록. 핵심 단서는 P22에서 별도 필수 제공 |
| marta_return, map_after, nia_return, nia_late, tracks_after | MQ06 이후 귀향 장면으로 유보. 프롤로그 종료 전에 재생하지 않음 |

니아 대화를 보지 않았는데 ‘지난 약속’을 언급하는 문제를 되살리지 않는다. 기존 니아 첫 대화·재대화·귀가 분기 판정은 그대로 보존한다. 후속 귀향에서 이미 작성된 marta_return은 긴급한 우물 확인 사건과 톤이 맞는지 별도로 조정한다.

사용 가능한 후보는 [최신 시안](../../visual-concepts.md), [NPC 목록](../../npc-registry.md), [환경 목록](../../environment-assets.md)에서 확인한다. 이미지 보드의 보유가 런타임 크롭·표정·걷기·라이선스 확인의 완료를 뜻하지 않는다. 음원은 사용 권한 확인 후 채택하고 파일명은 실제 선정 뒤 목록에 등록한다. 음성·새 전투 시스템·전 세계 맵 구현은 이 패키지의 선행 조건이 아니다.

고정 방향 카메라는 유지한다. 필요한 강조는 짧은 이동·확대나 초상화 전환으로 처리하고 회전 카메라를 넣지 않는다. 기준 1280×720과 글자 확대에서 대화창이 명령 메뉴·위험 범위를 가리지 않는지 외부 로컬에서 확인한다.

## 외부 로컬 작업 순서

1. **문서 대조:** 전체 대본과 현행 상태 구조를 읽고 기존 장면 재사용/대체 지점을 기록한다. 미정 스탯·회복품·표정 제작 범위를 제안하고 확정 기획을 변경하지 않는다.
2. **진행 연결:** MQ01~MQ05 상태와 장면 경계를 연결한다. 기존 심부름 자유 순서·출발 차단·재대화를 유지한다.
3. **첫 전투:** 같은 맵 전환·임시 검·부상 레온·정지 명령·이동/대기/회피/공격·승리/패배를 연결한다.
4. **저장과 재도전:** 소비 규칙·보상 1회·옛 저장 이관을 먼저 검수한다. 소모품 0개에서 진행 가능한지 확인한다.
5. **후반 대화:** 처치·부상 동행·돌샘 인계·차·다음 날 기록·귀향 결정을 붙인다.
6. **연출과 가독성:** 표정·발 위치·명령 UI·소리·시간 경과를 다듬는다. 게임 실행 검수는 전부 외부 로컬에서 한다.
7. **인계:** [완료 기준](acceptance.md)에 증거를 채워 구현 PR을 올린다. 문서상 계획과 구현 완료를 구별해 보고한다.
