# 외부 로컬 완료 기준·검수 기록

이 표는 **아직 수행하지 않은 검수 항목**이다. 이번 문서 작성 환경에서는 Godot·게임·게임 테스트를 실행하지 않았다. 구현 담당자가 별도 로컬에서 수행하고 결과·커밋·증거를 채운다.

## 완료로 인정하는 범위

새 여정에서 MQ01~05를 정상 완료하고, 첫 전투 패배·재도전·저장 복귀를 거쳐도 진행이 막히지 않아야 한다. 기존 대화 장면을 모두 보유한 것만으로는 완료가 아니다. MQ06 실제 귀향 구현은 이번 패키지 밖이며, 마지막에는 돌샘 안전 지점에서 다음 목표와 준비 상태를 전달할 수 있으면 된다.

30~45분은 플레이 관찰 목표이지 통과를 위해 늘려야 하는 분량이 아니다. 실제 소요 시간과 대사/이동/전투 비중을 기록하고 불필요한 반복을 줄인다. 30~60초의 일반 전투 목표를 튜토리얼 안내 대기 시간에 강제로 적용하지 않는다.

## 외부 로컬 결과 보고 양식

- 구현 PR·커밋:
- 기준으로 사용한 문서 커밋:
- OS·Godot 버전·실행/빌드 방식:
- 완료한 범위 / 남은 범위:
- A01~A35 결과 및 재현 절차:
- 신규 여정 정상 완주 영상:
- 첫 전투 패배→재도전 영상:
- 저장 복귀·구버전 이관 증거:
- 실제 플레이 시간·플레이어가 헷갈린 지점:
- 사용 자산·미완성 임시 표현·음원 권한 출처:
- 발견한 기획 충돌과 제안:

영상·스크린샷·로그에는 사용자 저장 경로 등 불필요한 개인 정보를 포함하지 않는다. 검수하지 않은 플랫폼을 지원 확인으로 표시하지 않는다. 여기로 전달받을 핵심은 결과물 링크와 남은 문제이며 현재 환경에서 게임을 다시 실행하는 것을 요구하지 않는다.
