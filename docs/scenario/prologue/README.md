# 프롤로그 구현 인계 패키지

**여기서는 대본·명세만 작성하고, 게임 구현·실행·테스트는 다른 로컬에서 진행한다.**

- [MQ01~05 전체 대본](full-script.md): 52장면, 대사·서술·선택·안내 331개 항목. 기존 일상 원고 재사용과 첫 전투·기록 확인·귀향 결정 신규 원고를 함께 수록.
- [연출·조작·진행·저장 명세](implementation-handoff.md): 장면 연결표, 전술 전투 튜토리얼, 소비품 미복구 재도전, 옛 저장 이관, 자산과 작업 순서.
- [외부 로컬 완료 기준](acceptance.md): 검수 35항목과 결과 보고 양식. 전부 현재 미수행.
- [문서용 장면 원본](scene-source.json): 런타임 데이터로 직접 사용하지 않는다.

기존 [프롤로그 원고](../../prologue-dialogue.md)와 게임 데이터는 변경하지 않았다. 본 패키지는 구현을 위한 상세 초안이며 게임 반영 완료를 의미하지 않는다. [상위 메인·서브 패키지](../README.md)의 이야기 흐름을 구체화한다.
