# 다른 로컬에서 수행할 완료 기준

2026-11-06. **모든 항목 미수행.** 이 패키지를 작성한 환경에서는 게임·Godot·게임 테스트·빌드를 실행하지 않았다. 구현 담당자가 별도 로컬에서 결과와 증거를 채운다.

## 정상 완료의 기준

## 외부 로컬 보고 양식

- 구현 PR·커밋 / 기준 문서 커밋:
- 선행 프롤로그·현행 진행과의 차이:
- OS·엔진 버전·실행 방식:
- B01~B33 결과·재현 방법·남은 항목:
- 서브 없이 MQ06~10 완주 영상:
- 조사·준비의 순서 변경 / 출발 취소 / 기간 경고 증거:
- 신규·구버전 저장 복귀 결과:
- 서브 중단·후반 재개 검증 여부:
- 실제 플레이 시간·다음 목적이 불명확했던 지점:
- 임시 자산·음원 출처·최종 아트 부족분:
- 지도/수송/기록 연표 가정과 충돌한 항목:

현재 환경에서 게임을 다시 실행하라고 요청할 필요는 없다. 결과물 링크·문제 재현·기획 충돌을 GitHub에 남기면 문서 보완으로 이어간다.
