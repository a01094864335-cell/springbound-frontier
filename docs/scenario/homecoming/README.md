- MQ07: 우물·약초밭·여관의 생활 피해 조사. 세 지점 순서 자유.
- MQ08: 장부와 가동 기록의 두 시기를 대조. 원인은 확정하지 않고 추가 확인 요청.

- MQ10: 변경된 통행 제한을 듣고 수송대를 대기소에 인계한 뒤 교량 외곽 확인.

**41장면·270개 대사/서술/선택/안내 항목**을 수록했다. 구성은 메인 22장면, 선택 분기 4장면, 서브 12장면, 재대화 3장면이다. 별도로 명세에 옛 귀향 저장용 X01 보충 대사 6항목이 있다. 이관 예외를 포함하면 전체 항목은 276개다.

서브는 새 ID를 늘리지 않고 기존 SE16 마르타 ‘가방의 무게’, SE19 니아 ‘끝나지 않은 눈사람’, SE20 오르만 ‘남은 수건들’, SE21 도렌 ‘누구의 장작인가’를 상세화했다. 메인 완료는 이 이벤트들에 의존하지 않는다.

선행 문서는 [프롤로그 MQ01~05](../prologue/README.md), 상위 흐름은 [메인·서브 패키지](../README.md)다. 본 작업은 PR #15의 문서에 이어지는 후속 자료이며 게임 코드·런타임 대화·에셋은 수정하지 않았다. 현재 완료한 것은 문서이며 검수표 33항목은 모두 외부 로컬에서 수행해야 한다.

문서 수정은 `scene-source.json`의 대사·진입·종료와 `full-script.md`의 대응 장면을 함께 갱신한다. 원본 JSON은 문서용 스키마이며 런타임 데이터로 그대로 복사하지 않는다. 상위 `build_scenario_docs.py`는 이 상세 대본의 생성 도구가 아니다.
