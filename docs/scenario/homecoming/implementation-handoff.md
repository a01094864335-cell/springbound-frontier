# 고향 귀환 편 외부 로컬 구현 명세

2026-11-06 · MQ06~10 상세 기획 초안. 게임 구현·실행·테스트는 다른 로컬 담당자가 수행한다. 현재 환경에서는 문서만 작성한다.

## 기준과 입출력

[확정 기획](../../confirmed-design.md) → [인물](../../characters.md) → [이야기 규칙](../story-bible.md) → [프롤로그 상세 명세](../prologue/implementation-handoff.md)를 함께 읽는다. 새 자료는 상위 확정을 자동 변경하지 않는다. 이번 범위에는 신규 전투·레온의 전투 복귀·리아 정식 합류·교량 구조전이 없다.

입력은 MQ05 완료, 약과 환자 인계 완료, 귀환 결정과 레온 동행 합의 상태다. 레온은 치료받았지만 아직 뛰거나 싸울 수 없다. 빌린 검은 돌샘에서 다시 허락받아 서리골까지 맡은 상태다. MQ06 시작 당시 HP·MP·소모품·직업을 변경하지 않는다.

출력은 MQ10 완료, 수송대의 대기소 인계, 교량 제한과 양안 미통과 인원 위치 확인, MQ11 시작 준비다. 이 문서의 ‘MQ11 준비’는 시작 완료가 아니다. 후속 구현 전이면 대기소에서 저장·종료할 수 있다.

## 이번 상세화에서 추가한 작업 가정

- 같은 산길에서 귀환 중 도렌의 동쪽 샘 길 점검을 만난다. 서리골 주민이 며칠 사이 모두 떠난 폐허로 만들지 않는다.
- 관측 세 지점은 우물·약초밭·여관이다. 여관 조사에서 환자 상황도 함께 확인한다. 개별 환자의 상세 병력 공개는 요구하지 않는다.
- 기존 MQ08의 ‘두 시기 비교’를 위해 돌샘에서 허가받은 사본에 과거 가동 구간도 들어 있었다고 상세화한다. 사본은 임무 전체 기밀 원본이 아니라 비교에 필요한 발췌다. 출처 없이 가방에 새 문서가 생기는 방식은 피한다.
- 피난은 가까운 대기소에 먼저 인계하고 교량 너머 구호소로 단계 이동하는 계획이다. 돌샘의 수용 여력이 제한적이라는 설명은 H12의 작업 가정이다. 지도상의 거리·지명·인구 숫자는 아직 확정하지 않는다.
- 교량 통행 제한은 기존 통행 가능 보고 뒤에 도착한다. 주민은 전방 대기소에 멈추고, 에일이 교량 외곽에서 직접 조건을 확인한다.

이 가정 중 지도·운용 설정과 충돌하는 부분은 구현 전 문서 수정으로 해소한다. 숫자나 실시간 타이머를 구현자가 임의로 정해 이야기의 원인을 바꾸지 않는다.

### 시작·완료 경계

- H04 진입 전에 MQ06의 필수 두 확인이 끝났는지 검사한다. 미완료면 도렌/관측 목표로 안내한다. 북문이 영구히 잠기는 연출 대신 들어가기 전 확인 대화를 연결한다.
- H09는 세 관측이 모두 있어야 진행한다. 덜 했으면 T01과 남은 목표만 표시한다. 이미 끝난 곳은 짧은 현황 재확인으로 대체한다.
- H11 마지막에 MQ08을 완료한다. 연락소 답장이 돌아와야 MQ09가 열리는 구조가 아니다.
- H17 마지막에 MQ09 완료와 SE16/SE20 해금을 처리한다. H18 상호작용 자체로는 MQ10을 시작하지 않는다.
- H18A 출발 확정과 MQ10 시작, 미완료 SE16의 현장 종료는 한 논리 작업으로 처리한다. 중간 저장으로 기간 경고를 우회하거나 두 상태가 어긋나지 않게 한다.
- H22 종료 후 MQ10 완료와 SE21 해금을 처리한다. MQ11은 별도의 이동 확인으로 시작한다. SE21을 보기 위해 MQ11을 먼저 완료할 필요가 없다.

## 조사 기록·증거의 의미

MQ07은 퍼즐 정답 찾기가 아니다. 세 지점에서 직접 확인한 변화를 짧게 기록한다. 조사 순서로 결론·주민 피해·보상이 달라지지 않는다. 각 관측 완료 시 아직 남은 지점을 목표에 표시하고 이미 본 곳은 반복 필수로 만들지 않는다.

MQ08의 비교 화면은 아래 두 구간을 나란히 보여주는 간단한 장부 연출로 충분하다. 새 연구 미니게임·달력 UI·수치 입력 시스템을 선행으로 요구하지 않는다.

| 비교 구간 | 가동 자료 | 마을 자료 | 확인할 수 있는 것 | 확인하지 못하는 것 |
|---|---|---|---|---|
| 과거 구간 A | 허가 사본의 과거 가동 일지 | 같은 밭의 채집/피해 기록, 발생 시기 확인 가능 | 가동 뒤 변화가 기록됨 | 다른 원인 배제·전체 지역 영향 |
| 최근 구간 B | 같은 사본의 최근 가동 기록 | 장부의 마지막 정상 채집과 피해 확인 기록, 우물 관측 | 같은 방향의 선후 관계 | 정확한 전파 경로·가동이 유일한 원인인지 |

이 표의 A/B는 제작용 구분자다. 최종 달력·날짜·시각은 세계 연표 검토 뒤 넣는다. 수신 시각만 아는 자료는 발생 시각으로 사용하지 않고 ‘미확인’에 둔다. P22에서 사본을 얻는 동작/출처 확인이 빠져 있다면 해당 접점의 대사 검토안을 구현 PR에 함께 제시한다. 프롤로그 런타임을 여기서 수정한 것으로 보고하지 않는다.

에일의 공명 능력, 네리아의 설명, 시설 연결·부담 전가의 확정은 여기서 공개하지 않는다. 세나·카이·이리스가 아직 없는 장면에 대사나 편리한 원격 해설로 등장하지 않는다. 레온의 국적을 확정하는 ‘우리 나라/너희 나라’ 대사도 넣지 않는다.

## 피난 동선과 책임

1. 서리골: 마르타가 치료/환자 인계, 오르만과 베라가 숙소/잔류 지원, 로크가 문·통행 보고·마지막 출발 확인을 맡는다.
2. 첫 수송: 도렌이 수레를 맡고 에일은 약 짐·환자 인계를 돕는다. 레온은 보고와 통행 확인을 담당하되 비전투 상태다. 에일이 다른 사람의 업무를 다시 전부 검사하지 않는다.
3. 전방 대기소: 출발 전 확인한 임시 수용처. 환자를 무조건 교량까지 밀어 넣지 않는다. H19의 새 제한 명령을 전달한 전령과 H20의 수신 담당자를 통해 보고가 실제 도착했는지 확인한다.
4. 교량 외곽: 에일과 레온이 접근 가능한 선까지 이동한다. 수송대는 대기소에 남는다. 반대편 미통과 인원과 이쪽 대기 인원은 별도 집계한다.
5. 뒤따르는 주민: 이 범위에서 마르타 일행의 도착·안전을 확인하지 않았다면 ‘이동 예정/확인 대기’로 남긴다. 이름을 적었다는 이유만으로 도착 처리하지 않는다.

연락은 전달편·전령·현장 담당자의 확인으로 진행한다. H11 질문의 답장은 후속 장으로 넘긴다. H19~H20 사이에는 실제 이동과 전달 시간 경과가 있으며 무전처럼 즉시 왕복하는 대사를 넣지 않는다. 통행 가능 정보에는 확인 시점을 붙인다. 오래된 보고를 현재의 절대 보장처럼 쓰지 않는다.

서브 장면은 메인 필수 플래그·기본 구호 물자·통행 허가·증거 확보를 해금하지 않는다. 아무것도 하지 않고도 MQ11 준비 상태까지 간다. 대사 태도는 이벤트의 후속 반응으로 남기며 호감도 수치·전투 보상·새 연애 규칙을 만들지 않는다.

### 같은 이벤트를 두 번 완주하지 않기

SE19/20/21은 장소가 바뀌어도 같은 ID다. 원래 해금 상태·선택·완료를 유지한다. 진행 중 이동했다면 다음 장면부터 문맥을 바꿔 재개하며 이전 선택을 다시 강요하거나 소품을 중복 획득하지 않는다. 표식/침구/장작은 이 원고에서는 대화 소품이며 신규 장비·자원 관리 시스템을 요구하지 않는다.

S19_1의 첫 세 줄은 모두 출력하는 대사가 아니다. **후반 거점 문맥을 최우선**으로 하고, 서리골에서는 프롤로그 니아 대화 관람 여부에 따라 ‘그때 만든’/‘내가 만든’ 중 하나만 쓴다. 후반에 시작할 때 표식은 피난 과정에서 니아가 스스로 챙긴 것으로 설명하므로 에일이 이벤트를 완료했다는 기억을 만들지 않는다. 그때 S19_2~3은 표식을 새로 얻는 일이 아니라 보관/안전한 새 자리 확인으로 연출한다.

SE20 후반 시작/재개에서는 S20_1 마지막 줄의 ‘아침에 가져온’ 표현을 ‘마을에서 가져온 수건도 여기 있네요. 이번에는 옮겨온 자리에서 정리하네요’로 대체한다. 후반 대사가 서리골 여관 안에서 벌어지는 것처럼 보이지 않게 한다.

SE16은 출발 전에 완료하지 못하면 `expired`와 실제 진행 지점을 남긴다. `completed`나 `SE16_summary`를 자동으로 주지 않는다. 후반 재회에서 요약을 들었을 때만 요약 확인 상태를 만들며 원 장면 완료와 구분한다. 후속 SE17 진입에서 ‘완료 또는 요약 확인’ 조건을 적용하는 것은 기존 [서브 원본](../side-events.json)의 대체 선행과 같다. 본 패키지는 아직 후반 재회 요약 전체 대본을 포함하지 않는다.

아래는 의미 이름이며 현재 게임에 이 이름의 변수가 있다는 뜻이 아니다.

| 이벤트 해금/단계/선택/완료/만료 | 각 이벤트 조건·마지막 페이지 | 재대화·기록창으로 다시 완료/지급하지 않음 |

대화 마지막 페이지를 닫을 때 완료하는 기존 방식과 원자적 진행 반영을 유지한다. 대화 중 저장/불러오기는 기존 제한을 따른다. 전투 밖 자유 저장, 각 MQ 경계의 자동 저장은 기존 슬롯 정책과 통합한다. 이 문서에서 슬롯 수나 저장 형식 버전을 새로 정하지 않는다.

재대화는 T01~03과 짧은 완료 현황을 사용한다. 이미 약을 전달한 상태에서 다시 배달을 부탁하지 않는다. MQ07 시작 이후에는 기존의 평온한 귀가 `marta_return`/`map_after`/귀향 니아 대사를 우선 재생하지 않는다. H05와 상태에 맞는 관측 대사가 해당 구간의 귀환을 담당한다. 기존 원고 자체는 삭제하지 않고 충돌한 트리거를 조정한다.

### 구버전·프롤로그 말미와 접점

[프롤로그 이관 규칙](../prologue/implementation-handoff.md)을 따른다. 옛 저장에 신규 MQ05 기록 확인/귀향 선택이 없다면 ‘이미 돌아왔으니 모든 단서를 알았다’고 처리하지 않는다. 다른 로컬 담당자는 기존 저장 상태를 조사한 뒤 아래 보충 대화를 적용한다.

- **기록 확인을 하지 않고 이미 귀가한 경우:** H05의 ‘기록에 서리골 이름’ 문장을 ‘우물 소식을 들었어요. 지금은 어떤지 보고 싶어요’로 바꾼다. H09 진입 전 로크의 전달 기록에 조사대가 보낸 허가 사본이 도착한 경위를 아래 X01로 제공한다. 기존 위치를 돌샘으로 강제 이동시키지 않는다.
- **이미 귀가했지만 신규 H02/H03이 없는 경우:** 원래 마을 위치를 유지한다. X01에서 귀환로 상태 확인을 함께 듣고 MQ06 접점을 충족한다. 일어나지 않은 귀환길 대화를 봤다고 표시하지 않는다.
- **다른 로컬이 이미 후속 장을 구현한 경우:** 현행 저장 스키마·진행 우선순위를 먼저 대조하고, 낮은 MQ 번호가 없다는 이유로 현재 위치·완료 상태를 되돌리지 않는다. 이관 계획과 결과를 구현 PR에 명시한다.

**X01 보충 대화** — 이관 경로에서만 로크의 첫 현황 확인. 일반 신규 경로와 중복 재생하지 않는다.

- **로크:** 돌샘 전달편에 레온 경의 귀환 기록과 발췌 사본이 왔소. 열람 허가도 함께 있소.
- **레온:** 내가 확인을 요청했던 자료군. 미확인 이름은 그대로 남겨두겠습니다.
- **에일:** 가동 기록과 마을 보고가 함께 있네요. 이걸로 원인을 알 수 있어요?
- **레온:** 시기를 대조할 수 있다. 원인은 더 확인해야 해.
- **로크:** 귀환로도 확인했소. 도렌이 샘 길을 점검했고 큰길은 아직 걸을 수 있다고 하오. 주민들은 우물 대신 샘을 쓰고 있고.
- **에일:** 그럼 먼저 집과 여관을 보고, 평소와 다른 걸 기록할게요.

X01은 41장면 원본 바깥의 이관 예외 원고 6항목이다. 적용 여부는 실제 저장 조사 뒤 결정하며 일반 플레이어에게 같은 단서를 두 번 주지 않는다.

## 공간·연출·에셋 연결

| 구간 | 필요한 표현 | 기존 자료와 추가 검토 |
|---|---|---|
| 귀환로 | 같은 굽이의 변화·도렌 수레·안전한 휴식 | 기존 산길/수레/나무와 에일 이동. 새 전투 적 불필요 |
| 서리골 | 우물 사용 제한·배급 통·얼어붙은 밭 | 기존 우물·밭·눈 환경 재배치. 우물 속 탐험/파괴 퍼즐 불필요 |
| 여관 | 환자 방·담요·마르타 위치 | 기존 오르만/마르타/NPC 보드. 집·여관에 같은 NPC 중복 배치 금지 |
| 장부 | 두 시기 비교·출처·미확인 표시 | 종이 소품과 대화창으로 충분. 전용 연구 시스템 불필요 |
| 출발 | 수레·적재 표·남은 주민·닫히는 문 | 원근·크기·발 위치를 맞춤. 모두 즉시 같은 수레에 실었다는 연출 금지 |
| 대기소/교량 외곽 | 안전한 숙소·수송 인계·통행선·양안 구분 | 기존 환경 보드에서 선정. 새 지도 최종 배치는 외부 로컬 검토 |

근거 목록: [NPC](../../npc-registry.md), [환경](../../environment-assets.md), [이동](../../ael-movement-assets.md), [장비/모션](../../combat-equipment-and-motion-spec.md), [시안](../../visual-concepts.md). 보드 보유를 완성 스프라이트·동작·맵 구현으로 표시하지 않는다.

고정 방향 카메라를 유지하고 필요할 때 짧은 정지·초상화·시선 이동으로 강조한다. 마르타는 기침만으로 쓰러지는 보호 대상이 아니라 치료와 인계를 맡는 인물이다. 에일은 완전히 성장한 해결사가 아니라, 일을 떠맡으려다가 주변의 도움을 받아 범위를 정하는 단계다. 위기 음악을 계속 크게 깔아 모든 대화를 재난 방송처럼 만들지 않는다. 환경음은 도르래의 멈춤·종이·수레·여관 난로를 활용하되 음원 권한·파일명은 선정 후 등록한다.

## 외부 로컬 작업 순서

1. MQ05 저장 접점·현행 맵·인물 위치와 문서 차이를 정리한다. 선행 PR #15 자료를 반영한 상태인지 확인한다.
2. MQ06~08 필수 진행과 자유 조사·기록 의미를 연결한다. 이관 예외는 신규 경로와 구분한다.
3. MQ09 역할 분담·순서 자유·경고·출발 선택을 연결한다. SE16 만료 처리를 먼저 확인한다.
4. MQ10 전달 시간·대기소·교량 외곽·다음 장 접점을 연결한다. 레온 전투 복귀를 앞당기지 않는다.
5. SE16/19/20/21과 프롤로그 관람 여부·이동 후 재개를 연결한다. 서브 없는 메인 완주부터 확인한다.
6. 저장·반복 대화·가독성·동행·다음 목표를 [검수표](acceptance.md)로 확인하고 구현 PR에 증거를 남긴다.
