# MQ16~42와 남은 개인·생활 이벤트 전체 인계

2026-11-06 · 제작 초안. **게임 구현·실행·테스트는 다른 로컬에서 진행한다.**

왕도에서 멈추지 않고 최종 정비·귀향까지 남은 메인 27개와, 아직 상세화하지 않았던 서브 19종을 작성했다. 선행 패키지와 합쳐 메인 42·서브 24 전체에 상세 원고와 구현 명세 위치가 있다.

이번 패키지는 메인 81장면·385항목, 서브 57장면·343항목으로 **138장면·728개 대사/서술/선택/안내 항목**이다. 별도 명세의 현장 만료 요약 12개와 기본 동료 후일담 5개는 이 수치 밖의 보충 원고다. 합치면 745항목이며 기존 패키지의 대사까지 포함한 전편 합계는 아니다.

원본의 A/B/C는 장면 순서이고 서브 B 내부의 선택 A/B는 한쪽만 재생한다. 등장 인물이 멀리 있으면 보고/전달로 분리하며 동료를 한 전투에 전부 배치하지 않는다. 이 JSON은 런타임 스키마가 아니고 상위 발췌 생성 도구가 이 상세 대본을 생성하지 않는다. 수정할 때 원본과 대응 Markdown·항목 ID를 함께 갱신한다.

선행은 [교량 편](../bridge/README.md), 상위는 [메인·서브 패키지](../README.md)다. 남은 것은 다른 로컬의 실제 구현·실행 검수와 수치·지도·연락 여력·최종 표현의 검토다. 이 변경에서 게임 코드·런타임 대화·에셋을 수정하거나 게임을 실행하지 않았다.
