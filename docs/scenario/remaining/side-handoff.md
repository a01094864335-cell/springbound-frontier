# 남은 서브 이벤트·조건·접점 명세

기존 SE01~24의 정체성과 해금/선행/기한을 유지한다. 이번에 19종을 57장면으로 상세화했고 선행 패키지의 5종과 합쳐 24종 모두 상세 원고를 갖춘다. 새 이벤트를 24개 더 만든 것이 아니다.

원본은 [side-scenes.json](side-scenes.json), 대본은 [side-scenarios.md](side-scenarios.md)다. 해금은 지정 MQ **완료 후**이며 A는 도입·기존 핵심 대화, B는 태도 선택 한쪽, C는 인계와 마무리다. 모든 선택은 우정·신뢰 중심이고 자동 연애가 아니다. 기본 물자·조사·정비 인력·최종 성공을 해금하지 않는다.

## 장소·순서·소품 분기

- SE01은 돌샘 치료 중 현장 한정이다. 후반에 똑같은 부상 상태로 돌아가서 재생하지 않는다. MQ05 완료 시 경고, MQ06 출발 전 재확인하고 떠나면 expired로 남긴다. 후속 개인 편은 아래 요약을 실제 보았을 때 대체 진입한다.
- SE02는 레온의 군 보고와 별개로 가족에게 보내는 개인 편지다. 본편 조사대 확인 요청을 이 이벤트를 해야 시작하도록 바꾸지 않는다. 불명인 대원의 생사나 이름을 새로 확정하지 않는다.
- SE03은 MQ20에서 보관 기간을 갱신한 빌린 검을 반환한다. 전 무기 선택 가능은 유지하고 검을 무조건 최종 무기로 장착시키지 않는다. 다른 로컬이 앞서 검을 반환/회수했다면 ‘그 검을 돌려드릴 때 말하지 못한 게 있어요’로 추억 문맥을 바꾸고 실물 재지급/재반환을 하지 않는다. 소유·보관·장착은 별개다.
- SE05는 안전한 귀환 조사 신청을 함께 만드는 사건이다. 실제 위험 지역으로 민간인을 보내거나 서브 선택으로 치명적 사고를 강제하지 않는다.
- SE06/09/12는 MQ36 완료 후 중추 출발 전에도 가능하지만 그때 안 했다고 자동 실패하지 않는다. 후속 안전 거점이나 해금된 후일담 접점에서 현재 문맥으로 재개한다. ‘곧 출발’ 대신 ‘다음 출발 준비’로 바꾸고 원래 장면을 봤다는 기억을 생성하지 않는다.
- SE07은 기존 오류를 정정하는 개인 사건이다. 메인 핵심 가설의 근거 전체가 이 한 오류로 무너졌다고 추가하지 않는다.
- SE08은 불확실해도 안전한 우회로를 설명하는 역할, SE09는 동의·중단·열람 조건을 같이 정하는 역할이다. 연애 동의서나 에일의 신체 권한을 연구자가 갖는 계약으로 쓰지 않는다.
- SE10/11/12의 선원 몫·허가받은 물건·잔류 의지는 서로 이어진다. 가족 물건은 장비/돈 보상이 아니라 인계 소품이다. 지연 중 출항을 약속하지 않는다.
- SE13은 보호할 신원과 지원 누락 사실을 분리한다. SE14는 과거 책임을 묻는 일과 지금 돌봄을 병행하며 돕는 일을 면책으로 처리하지 않는다. SE15는 기록의 지속적 인계이지 모든 재판의 종결이 아니다.
- SE17은 **작성→선택→실제 전달 시간 경과 뒤 회신** 순서다. 원본 대사를 C에 재배치해 답장이 보내기도 전에 도착하지 않게 했다. 회신이 오기 전 ‘답장 대기’를 표시하고 다른 본편 행동을 할 수 있다. 해금된 후반에 시작하면 최근 전달편과 회신으로 처리한다.
- SE18은 약초밭의 작은 구역만 회복된 귀향 후일담이다. 에일의 직업을 약초사로 확정하거나 농장 경영 시스템을 요구하지 않는다.
- SE22의 펠은 연락 업무로 왕도/후반 거점에 온 상태를 짧게 설명한다. 돌샘에 고정해둔 NPC와 동시에 복제하지 않는다. 수신 표기 정정은 본편 필수 통신 규칙을 대체하지 않는다.
- SE23은 초반에는 실제 손 상처, 후반에는 현재 손 상태 확인으로 연출한다. 오래된 우물 상처가 몇 달째 같은 상태라고 쓰지 않는다. 앞의 위생 실수를 회상할 때는 ‘처음엔 그랬죠’로 시제를 바꾼다. 환자 우선순위를 호감 선택으로 정하지 않는다.
- SE24는 본편 제한 통행 이행 확인 뒤의 생활 변화다. 이 가족이 배를 타야만 협상 성공이 되는 조건을 추가하지 않는다.

같은 ID의 장소만 바뀐 사건을 별도 이벤트로 보상하지 않는다. 진행 단계/선택/완료를 유지하고 다음 미완료 장면부터 재개한다. 약·표식·수건·밧줄·가족 물건·계약서·노트는 실제 게임 아이템 여부를 별도 검토하며 대사 재생으로 자동 장비 지급하지 않는다.

## 놓친 현장 이벤트의 요약 원고

아래는 side-scenes.json 바깥의 보충 12항목이다. 원 이벤트가 만료됐고 아직 요약을 보지 않았을 때만 제공한다. 요약을 들었다는 상태는 원 장면 완료와 구분한다. 이미 원 이벤트를 완료했다면 같은 이야기를 다시 완료할 필요 없다.

### SE01-SUM — 실제 요약 관람 후 SE01_summary

- 에일:돌샘에서 치료받을 때는 장비를 누가 챙겼어요?
- 레온:내가 직접 보려고 했지. 맡기는 법을 잘 몰랐던 때군.
- 에일:그때 더 도와드릴 수도 있었겠네요.
- 레온:지금은 내 부탁을 먼저 설명하려고 한다. 다친 사람이 무엇을 할 수 없는지 말하는 것도 일이더군.
- 에일:그럼 다음에 혼자 붙잡고 있는 일이 있으면 물어볼게요.
- 레온:좋다. 편지도 하나 같이 봐줄 수 있겠나.

### SE16-SUM — 실제 요약 관람 후 SE16_summary

- 마르타의 편지:짐을 다시 살필 때 네 몫의 옷도 남겨뒀기를 바란다.
- 에일:제 몫을 빼면 남에게 더 줄 수 있는 줄 알았어요.
- 레온:네가 버틸 몫을 누가 대신 챙겼는지도 생각해봐라.
- 마르타의 편지:나도 이웃에게 일을 나눴어. 부탁할 사람 이름을 알면 떨어져 있어도 덜 막막하단다.
- 에일:다음 소식에는 누구에게 맡겼는지도 적을게요.
- 서술:에일은 편지를 접고 자기 식량을 확인했다. 보지 못한 마을의 대화를 보았다고 기억하지는 않았다.

SE01 요약은 만료 후 레온에게서, SE16 요약은 늦어도 MQ26 이후 받은 전달편에서 선택 관람할 수 있다. 만료 사실만으로 요약 상태가 자동 생성되지 않는다. 편지는 즉시 답장하지 않고 전달 시간을 따른다. 이 보충으로 후속 개인 이벤트의 진입이 불가능해지는 문제를 피하되 과거 선택·보상은 소급하지 않는다.

## 저장과 완료

해금/선행 충족/진행 장면/선택/전달 대기/완료/만료/요약 관람을 구분한다. 조건에 맞지 않으면 NPC의 현황 대화와 다음 기회를 표시한다. 마지막 C 장면을 마쳐야 완료하며 기록창·같은 장소 재진입으로 다시 지급하지 않는다.

MQ42 후일담은 선행을 만족한 장면만 감상 목록에 연다. 본편 엔딩을 가리거나 최종 성공 조건을 바꾸지 않는다. 선행 미완료라도 본편의 기본 동료 근황은 [결말 규칙](combat-and-contact.md)에서 별도 제공한다. 연애 후보·임계값·복수 관계는 확정하지 않는다.
