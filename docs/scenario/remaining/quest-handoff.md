# MQ16~42 장별 플레이·연출·완료 명세

2026-11-06 · 다른 로컬 구현 담당자에게 전달하는 제작 초안. 현재 환경에서는 게임 코드·런타임 대화·에셋을 수정하거나 Godot·게임·게임 테스트·빌드를 실행하지 않는다.

## 문서의 의미

[확정 기획](../../confirmed-design.md)·[인물](../../characters.md)·[세계 규칙](../story-bible.md)을 우선한다. 선행은 [교량 편](../bridge/README.md)의 MQ15 완료/왕도 외곽 수령 기록이다. A/B/C는 대사의 도입/핵심/인계 장면이며, 세 문단을 연속 재생하고 퀘스트를 끝내는 구조가 아니다. 아래 실제 플레이·판정을 중간에 연결한다. 구체적 키·좌표·적 수·피해량·보상·체류 일수·세이브 버전은 확정하지 않는다.

본편 결말은 하나다. 선택 이벤트를 하지 않아도 필수 자료·인력·연락·구호·중추 정비를 확보한다. 이번 문서에서 추가하는 시설·지도·운영 세부는 작업 가정이며 기존 확정 기획을 자동 변경하지 않는다.

실베르가 모든 창구를 직접 조작한 것으로 시작하지 않는다. 누락·수신·승인 이력을 확인해 의도적 은폐 의혹에 접근한다. 책임 확정과 실제 심판은 최종 기록 보전 이후에도 남는다. 행정 절차만으로 감정을 잃지 않도록 지원 창고에서는 물자를 기다리는 사람의 이름과 현장 인수 기록을 짧게 회상한다. 새 강제 전투·감옥 탈출을 덧붙이지 않는다.

레온은 교량에서 비전투였고, 왕도 체류와 치료 기록·재진료를 거친 뒤 활동을 재평가한다. MQ20 이후 편성 가능을 열어두는 작업안이며 전투 직전 상태 점검·통증의 한계를 남긴다. 시간 경과 장면 없이 갑자기 완치시키지 않는다. 치료 장면이 모든 HP/MP를 무료로 채우는 것은 아니다. 검은 MQ20에서 여정 종료까지 보관을 다시 부탁받되 장착을 강요하지 않는다. 에일은 다른 무기를 사용할 수 있고 검의 소유와 현재 장착은 별개다.

에일의 감각은 이번에 설명 가능한 단서로 발견되지만 세계를 읽는 만능 능력이 아니다. 언제든 독립 계측·기록을 함께 사용한다. 다른 역할의 주인공으로 교체하지 않는다. 세나는 자기 이름을 걸고 한계를 공개하며 동행한다. 연구 대상에게 강제로 실험하는 장면을 멋진 연출로 포장하지 않는다.

현장 안전 준비는 메인에 포함한다. 시험을 플레이어가 수치 최적화로 반복하는 연구 미니게임으로 만들지 않는다. 허가 범위 밖 입력은 실행 전에 차단하고 이유를 안내한다. 필수 단서는 조사 순서와 관계없이 같은 의미를 가지며 ‘느낌이 강한 선택’이 정답인 추리 분기를 만들지 않는다.

선원 구조는 해안 접근·경로 확보·들것/인수 역할 분담으로 한다. 수영·선박 조종·바다 전투라는 새 게임을 자동으로 요구하지 않는다. 선택적 일반 전투를 넣는다면 기존 전투 시스템과 적 자료로 별도 설계하며 본 대본이 전투 구현까지 확정했다는 뜻이 아니다.

카이는 거래를 중시하지만 사람을 무시하는 인물에서 갑자기 개심하는 것이 아니다. 처음부터 선원 몫과 구조 우선 기준을 드러내고, 나중에 자신의 의지로 잔류한다. 이리스와의 첫 면담은 MQ32이며 MQ31의 목록 전달은 연구 연락망을 통한 업무 연락이다. 만나지 않았는데 오랜 개인적 친분을 회상하지 않는다.

MQ35는 기존 지역을 무작정 전부 걷게 하는 심부름 목록이 아니다. 통합 구호 거점에서 각 담당자 인수 상태를 확인하고, 실제 빠진 필수 항목만 관련 현장으로 연결한다. 이동 불가 지역 때문에 메인 물자가 잠기지 않게 대체 접근/인수 창구를 제공한다. 자원량·기부 경제의 임의 수치로 메인을 막지 않는다.

세계 규칙상 여력은 유한하다. 합의에는 최대 대기·시작 취소·현장 안전 유지가 들어간다. 늦어도 계속 기다리면 성공하는 구조가 아니며, 후속 MQ40은 이 규칙을 실제 지키는 사건이다.

MQ42 원고 B의 앞 6줄은 복구 거점, 뒤 6줄은 시간 경과 후 마르타 집이다. A/B/C 전체를 한 장소에서 연속 재생하지 않는다. 레온 고향 후일담은 국적·지도 미정이므로 새 필수 방문 맵으로 만들지 않는다. 편지/회상/허가된 후일담 표현으로 유보한다.

## 전체 공통 저장·재대화

각 MQ의 도입/필수 확인/인계/완료를 구분한다. 진행 중 저장은 전투 밖 자유 저장과 기존 대화 중 제한을 따른다. 마지막 페이지를 닫았다고 실제 수송·인수·타격·자료 보전이 자동 완료되지 않게 판정을 분리한다. 로그 재열람·반복 대화·일시정지로 지급·소비·승리·선택이 중복 실행되지 않아야 한다.

표시할 목표는 ‘다음 미완료 필수 항목’이며 이미 확인한 곳을 다시 강제하지 않는다. 퀘스트 번호가 낮은 플래그가 없다는 이유로 다른 로컬의 후속 진행을 되돌리지 않는다. 구버전 이관은 현행 저장 조사·원본 보관·새 항목 의미 매핑을 먼저 하고 별도 구현 PR에 제시한다.

전투 소비품 미복구·전투 후 HP/MP 유지 규칙은 그대로다. 여행 암전·의무실·차·연출 속 휴식이 무료 전원 완전 회복을 뜻하지 않는다. 명시된 기존 회복 수단을 제공하고 소모품/MP 0에서도 요구되는 조작 자체를 할 수 있는지 확인한다.

이 패키지의 완료는 문서 작성 완료다. 실제 맵·UI·애니메이션·행동/시간/저장·플레이 시간·플랫폼 검수는 [외부 로컬 검수표](acceptance.md)를 따라 별도로 수행한다.
