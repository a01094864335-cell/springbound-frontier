# 후반 전투·공동 작전·연락·결말 규칙

2026-11-06 · 제작안. 게임 구현·실행·수치 밸런스 검증은 다른 로컬에서 수행한다.

## 본편 전투 연결

MQ16~36은 대화·조사·구조·협상·준비가 필수 진행이다. 각 이동 구간에 일반 전투를 배치할 수 있지만 본 대본은 매 퀘스트에 새 필수 보스를 요구하지 않는다. 특히 서류 열람을 군 기록 절취전으로, 선원 구조를 새 배 조종 게임으로 바꾸지 않는다.

MQ37과 MQ41은 필수 스토리 전투다. 탐험하던 맵에서 시작하며 전술 명령 중 시간 정지·실행 중 재개한다. 탐험 주인공은 에일에 고정하고 다른 지역의 조작 가능한 팀으로 시점을 넘기지 않는다. 출전은 에일 포함 최대4명이다. 동료 여섯 명을 한 전투 화면에 전부 배치하지 않는다.

### MQ37 진입 호위

| 단계 | 판정·플레이 | 실패·안내 |
|---|---|---|
| 준비 | 출전 편성·수리조/장비·목적지·예비 통로 확인. 준비 중 임무 시간 미진행 | 필수 확인이 없으면 시작 전에 안내 |
| 진입 | 길목을 확보한 뒤 수리조 이동, 위험할 때 안전 지점 대기 | 경로가 막혔다는 UI, 길찾기 버그를 패배로 쓰지 않음 |
| 인수 | 필수 인원·장비가 입구 인수 영역에 실제 도착 | 적 전멸·대사 재생만으로 완료 금지 |
| 종료 | 예비 퇴로 확보와 입구 점검 완료 후 담당자 인수 | 구조 인원 미인수/핵심 임무 불능 시 직전 재도전 |

장비/수리조를 하나의 보호 임무로 표현해도 되며 개별 노동자 관리 시스템을 새로 만들 필요는 없다. 필수 수리조 전투불능 같은 실패 조건은 현행 임무 판정과 일치시키고 실제 적 수·위협·기한은 별도 검증한다. 무한 증원 전멸·새 필수 도발/밀치기/마법·특수 무기를 성공 조건으로 쓰지 않는다.

### MQ41 중추 전환 저지와 인수

| 단계 | 플레이 목표 | 실제 통과 조건 |
|---|---|---|
| 준비 | 모든 필수 거점의 수정 시각 확인, 출전/연락/측정 담당 분리 | MQ40 합의·현장 준비·안전 여력 계측 확인 |
| 강제 전환 저지 | 네리아가 시작한 강제 제어를 현장 제어부에서 차단 | 적 저지와 제어부 접근/조작의 실제 판정. 네리아 살해를 유일 조건으로 삼지 않음 |
| 안전 유지 | 필요한 제어 지점·퇴로를 지키고 안전 운용 상태를 확보 | 표시된 현장 안정 조건 충족. 에일의 감각 한 번으로 장치 전체 초기화 금지 |
| 확인 창구 | 운용 담당 교대와 전달 시간 경과를 장면 전환으로 보여주고 필수 거점 보고 수신 | 각 보고의 거점 ID·시각·정비 완료 구분. ‘시작했다’는 보고를 완료로 쓰지 않음 |
| 최종 인수 | 남은 현장 위협을 해소하고 담당자에게 운용/감시를 넘김 | 전환 중지+안정 조건+모든 필수 완료 보고+인수 확인 |

제어부를 두고 벌어지는 국지 전투와 유지/교대/연락 확인을 나누어 표현한다. 대륙 전령이 몇 초 만에 왕복하는 것처럼 한 전투 타이머 안에 압축하지 않는다. 안전 유지 상태를 확보한 뒤 훈련된 현장 인원이 교대하고, 정해진 관측 여력 안에서 기다리는 시간은 장면 전환으로 경과시킨다. 모든 시간 동안 에일이 혼자 맨손으로 버티는 설정이 아니다.

여력은 MQ36과 MQ40에서 확인한 범위만 사용한다. 시간 경과 장면이 에너지를 새로 만들거나 무료 완전 회복을 제공하지 않는다. 정해진 범위 안에 수신할 수 없으면 시작을 보류/취소하고 준비 상태로 돌아간다. 시행 후 복구 불가능한 무한 대기 상태를 만들지 않는다. 이 구체적 대기 길이·교대 간격·전투 시간은 세계 지도와 연락 소요를 대조해 구현 전에 산정한다.

비출전 동료는 측정·연락·구호 등 역할을 갖는다. 본문에 인물이 발언한다고 동시 전투 인원이 늘어나는 것은 아니다. 세나가 출전하면 훈련된 현장 계측 담당자가 기본 관측을 잇고, 이리스가 출전하면 연락 담당자가 보고를 읽는다. 특정 개인 서브 완료만으로 이 대체 인력을 해금하지 않는다. 대사는 현장에 있으면 직접, 떨어져 있으면 전달된 보고의 복창으로 보여준다.

네리아의 계획은 일부를 지키되 희생 지역을 고정하는 선택이다. 주장 일부가 현실적인 위협을 짚어도 강제 결정의 책임은 남는다. 전투 후 무조건 처형·화해·즉시 사면이라는 이분법을 만들지 않는다. 신병·권한·조사 기록의 인계를 별도 확인하고 최종 법적 결론은 후일담에서도 열린 과제로 남길 수 있다.

## 시간·실패·재도전 공통

전술 정지·명령 메뉴·필수 설명 중 적/호위/임무 제한 시간이 모두 함께 멈춘다. 설정·기록창·포커스 변경의 정지 정책도 현행 규칙과 일치시킨다. 설명을 읽는 시간이 손해가 되는 숨은 카운트를 넣지 않는다. 실행 중 경고는 텍스트/아이콘/지형으로도 표시한다.

임무 실패는 전투 직전 HP·MP·위치·퀘스트·보상으로 복귀한다. 소비 아이템은 돌려주지 않는다. 같은 재도전 보관본을 읽을 때마다 초기 소지량이 부활하는 구현을 금지한다. ‘안내 다시 보기’는 조작/목표 안내만 반복하고 장의 긴 대사를 강제로 재생하지 않는다. 수동 과거 저장의 정책·슬롯 수·버전은 여기서 새로 정하지 않는다.

HP/MP는 전투 후 유지한다. 소모품이나 MP가 0이어도 필요한 이동·일반 명령·제어 조작을 실행할 수 있어야 한다. 진행 전에 기존 회복 수단과 준비 기회를 안내한다. 승리 보상·권한 차단·현장 인수는 각 1회만 반영하고 로그 재열람/장면 재진입으로 반복하지 않는다. 단계별 체크포인트를 둘지, 동일 전투 전 보관을 사용할지는 확정 저장 규칙을 기준으로 구현안에 명시한다.

## 연락과 거점 ID

MQ35에서 필수 거점 목록을 확정하고 MQ36의 합의 판본에 같은 ID로 넣는다. 최소 기능 구분은 **현장 정비, 민간 이송/구호, 수송/연락, 중추 운용**이다. 이는 맵 4개 고정이나 각국 4개 확정을 뜻하지 않는다. 실제 거점 수·지명·담당자를 작성한 뒤 누락/중복 없이 검증해야 한다.

신호 종류는 준비, 시작 가능, 시작 수신, 정비 완료, 중단 요청, 중단 수신으로 구분한다. 번호·판본·보낸 시각·수신 시각·담당자가 붙는다. 한 신호를 다른 뜻으로 재활용하지 않는다. 에일의 감각은 통신 수단이 아니다. 전령·연락소·봉인 사본·항구 전달편으로 보내고 고정 응답 창구와 예비 경로를 둔다.

MQ34는 동시 원격 협상이 아니라 여러 차례 전달과 면담이다. MQ40은 답이 늦으면 보류하고 예비 전달로 이송 지연을 확인하는 사건이다. 남은 안전 여력을 다시 확인한 뒤 모든 필수 거점이 새 판본을 받았을 때만 시작한다. 미응답을 준비 완료나 배신으로 바꾸지 않는다. 실베르가 중추에 있는 이유는 MQ34에서 왕국 감독 대표 파견을 합의했기 때문이다.

## 정보 공개 순서

- 왕도: 공식 발표의 모순과 누락 확인. 시설이 재난의 유일 원인이라고 발표하지 않음.
- 학술도시/북방: 감각의 한계·장치 연결·완충과 지역 간 부담을 관측. 외부 경고에서 추가 시험 보류.
- 해양국: 독립 출처로 방향/지연을 검증. 발테르의 목적 설명과 침공 책임을 함께 다룸.
- 성역: 안전한 단계 정비의 물자/피난/동의 조건. 개인 신원 공개를 해결의 필수 대가로 요구하지 않음.
- 중추: 중앙 강제 전환의 희생과 준비된 대안 비교. 새 신/마지막 비밀 병기로 앞의 준비를 무효로 하지 않음.
- 귀향: 피해의 점진적 회복. 눈이 모두 녹지 않아도 생존·운용·감시 인계와 관계 변화가 결말의 의미가 됨.

## 단일 본편 결말과 후일담

MQ42의 필수 귀향·마르타 대화는 모든 정상 본편 완주자가 본다. 개인 이벤트가 없어도 다섯 동료에게 각각 짧은 기본 근황을 제공한다. 상세 개인 후일담은 해당 이벤트 해금·선행을 충족했을 때만 추가한다. 우정만으로 완결되며 연애 대상 명단·단계 수치·복수 관계 처리는 여전히 미확정이다.

**기본 근황 대사** — 개인 이벤트 완료와 무관한 본편 엔딩 후 선택 감상. 아래 원고는 main-scenes.json 바깥의 보충 5항목이다.

- 레온:이제는 보고에도 함께한 사람 이름을 남긴다. 다음 길도 혼자 정하지 않을 생각이고.
- 리아:돌아온 사람을 확인하고, 아직 기다리는 이름도 남겨뒀어요. 저 자신도 그 명부에 적었습니다.
- 세나:확인한 범위와 모르는 범위를 함께 발표했어요. 다음 사람이 다시 측정할 수 있도록요.
- 카이:다음 배는 준비 중이야. 갈지 말지는 그때 고르자. 연락할 곳은 서로 알고 있으니까.
- 이리스:기록을 맡을 사람을 더 정했습니다. 저도 자리를 비웠다가 돌아올 수 있도록요.

이 대사들은 특정 사건을 플레이어가 봤다고 회상하지 않는 기본 근황이다. 최종 정비의 본편 역할은 경험했으므로 그 범위에서 변화가 드러난다. 귀향 직후 갑자기 모든 논문·행정 조사가 완료된 것으로 보이지 않도록 시간 경과가 있는 후일담 카드로 연출한다.

상세 후일담은 엔딩 감상 목록에서 해금한 장면을 선택해 본다. 새 자유 탐험/반복 파밍/귀환 뒤 전체 월드 재개방을 이번 기획에 자동 추가하지 않는다. 최종 시안·플레이 시간·음악·성우·새 NPC 보드도 문서 보유만으로 완료라 하지 않는다.
