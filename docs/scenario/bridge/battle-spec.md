# MQ13 호위·철수 전투 명세

제작용 규칙 초안. 수치·적 수·맵 치수·보상은 미확정이며 외부 로컬에서 검증한다. 현재 게임에 구현되었다는 의미가 아니다.

## 목표와 편성

승리 조건은 **필수 수레의 A안 인수 완료 AND 에일 철수 AND 리아 철수**다. 적 전멸·수레 도착 알림 재생·레온의 대사 종료는 승리 조건이 아니다.

탐험 맵에서 전투를 시작한다. 조작 가능한 출전 인원은 에일·리아 2명이며 각각 이동·일반 공격·대기·허용된 아이템 명령을 받는다. 레온은 A안의 비전투 담당자다. 그를 선택해 공격시키거나 적의 유인 대상으로 쓸 수 없다. 첫 전투가 아닌 첫 동료 전투이므로 B09에서 선택 인물 변경과 각자의 명령 확인을 안내한다.

신규 방패·회피 키·도발·밀치기·마법을 필수 해법으로 요구하지 않는다. 위험 회피는 기존 이동 명령으로 한다. ‘길목을 비운다’는 적을 저지하거나 유효 경로를 확보한다는 뜻이며 물리적으로 적을 밀치는 새 기술을 뜻하지 않는다. 리아의 기본 창·에일의 임시 검으로 역할을 나눌 수 있는 구조여야 한다.

## 상태 전이

| 단계 | 진입 | 실행 | 다음 단계 |
|---|---|---|---|
| 준비 | MQ12 수리/탑승/퇴로 완료 | 편성·장비·B09~10 안내. 전투 시간 시작 안 함 | 시작 확정→호위 |
| 호위 | 전투 실행 확정 | 수레는 B안에서 A안으로 이동, 적은 B안 접근로에서 진입 | 필수 수레 인수→철수 |
| 철수 | 인수 판정 완료 | 수레는 안전 구역 고정, 두 출전 인물에게 철수 명령 | 둘 다 안전 구역→승리 |
| 승리 | 세 목표 동시 충족 | 보상·MQ13 완료 각 1회, B11 | MQ14 |
| 실패 | 필수 수레 파괴/출전 핵심 인물 전투불능/철수 기한 미달 | 원인 표시, 실행 중지 | F01→전투 직전 재도전 |

핵심 인물 한 명의 전투불능으로 실패하는 조건은 **이 임무의 제안 규칙**이다. 전체 전투의 상시 규칙으로 확대하지 않는다. 부활 아이템 사용을 성공 전제로 만들지 않기 위한 구조이며, 현행 전투가 전투불능 후 부활을 허용하는 경우에는 임무 실패와 충돌하지 않도록 구현 전에 조정안을 기록한다. 어느 경우든 죽음·이탈을 정사로 확정하지 않고 재도전으로 돌아간다.

MQ13 중간에 새 자동 저장을 만들어 실패한 호위 상태를 재도전 시작점으로 삼지 않는다. 복귀는 전투 시작 전이며 실제 소비한 아이템만 되돌리지 않는 확정 규칙을 적용한다.

## 수레·인수 판정

- 수레와 필수 탑승 인원은 하나의 호위 대상으로 취급한다. 개별 민간인의 체력/AI/회복 시스템을 추가 선행으로 요구하지 않는다.
- 수레는 정해진 유효 경로를 따라 이동한다. 적의 접근으로 경로가 위험해지면 안전 지점에서 멈추고 E01과 HUD의 ‘통로 대기’를 한 번 알려준다. 길이 다시 확보되면 재개한다.
- 수레는 보호 대상이며 공격 위험과 상태를 읽을 수 있어야 한다. 체력·이동 속도·위협 판단 범위·적의 대상 우선순위는 현행 전투 데이터에서 조정한다. 수치 확정 없이 문서만으로 밸런스 완료라 하지 않는다.
- 아군·수레의 충돌로 영구히 막히지 않게 경로 폭과 배치를 검수한다. 길찾기 결함을 플레이어 실패로 취급하지 않는다. 회복 아이템이나 특수 기술을 길막 해결책으로 강제하지 않는다.
- A안 도착은 수레의 실제 인수 영역 진입, 탑승자 표시 유지, 인수 담당자 수령이 모두 충족된 시점이다. E03을 재생하는 함수 자체를 성공 조건으로 삼지 않는다.
- 수레 인수 뒤 적이 안전 구역으로 들어와 이미 인계한 환자를 다시 파괴하지 않는다. 안전 구역은 같은 맵 안에서 경계가 명확해야 하며 적의 공격을 피하는 무한 공격 거점으로 쓰이지 않도록 전투 영역을 구분한다.

## 철수와 제한 시간

한정된 방어 가능 시간을 압박으로 사용하되 **정확한 초·증원 수·공격력은 아직 미정**이다. 실제 실행 시간을 기준으로 호위와 철수를 합산한다. 준비·명령 선택·튜토리얼·대화·설정·필수 메뉴로 정지한 동안은 수레·적·제한 시간이 모두 멈춘다. 창 포커스 변경의 정지는 현행 일시정지 정책과 통일하고 일부만 흐르지 않게 한다.

철수 여유와 경고 구간을 HUD에 표시하고, 임박 시 E02와 퇴로를 강조한다. 먼저 고지하지 않은 숨은 카운트로 실패시키지 않는다. 설명을 읽거나 동료에게 명령을 내리는 사람이 불리해지지 않아야 한다.

에일과 리아가 각각 철수 구역에 들어와 살아 있는 상태일 때만 출전 인원 철수로 판정한다. 한 명이 남았는데 자동으로 끌어오거나, 선택한 캐릭터만 이동시키고 전원을 탈출시킨 것으로 처리하지 않는다. 두 인물이 철수한 뒤에는 AI가 다시 적에게 돌아가지 않는다. 두 인물 모두 전투 명령 대상이므로, 한 명은 필수 구역으로 보낸 뒤 다른 사람을 선택해 이동할 수 있어야 한다.

예비대는 철수 완료 뒤 방어 인계 연출을 맡는다. 수레 미인수나 제한 시간 미달을 자동 성공으로 바꾸지 않는다. 충분한 초반 여유와 단계별 경고가 있어 초견 플레이어도 전멸을 노리지 않고 목적을 이해할 수 있는지 검증한다.

## 적과 증원

접근 방향·증원 지점·아직 미확인인 바깥 구간을 구별한다. 적이 수레 바로 옆이나 아군 뒤에서 예고 없이 생성되지 않는다. 저지할 소규모 선두와 뒤따르는 압박을 구분하고, 모든 적을 쓰러뜨릴 필요가 없음을 화면과 대사로 일치시킨다.

증원 패턴은 유한한 임무 압박용으로 설계한다. 무한 경험치/아이템 수급을 전제로 하지 않는다. 정확한 역할·병종·보드·수량과 보상은 기존 적군 자료와 일반 전투 정책을 대조한 뒤 결정한다. 비출전 레온에게 피해를 몰아 넣거나, 필수 새 마법을 써야만 막을 수 있는 적을 추가하지 않는다.

## 실패·재도전·회복

전투 전 HP·MP·위치·편성·장비·퀘스트 단계·전투 보상을 복귀 기준으로 보관한다. 소비품은 실제 사용 판정 시 한 번 차감하고, 같은 재도전 세션에서 사용 내역을 유지한다. 단순 보관본 로드로 초기 아이템 수량을 복구하지 않는다. 전투 보상은 실패 시 유지하지 않는다.

F01의 ‘다시 도전’은 B01~B08 장문을 반복하지 않고 전투 직전으로 돌아간다. ‘안내 다시 보기’는 B09~10만 제공한다. 둘 다 같은 재도전 소비 내역을 사용한다. 저장 선택 화면으로 나갔다가 동일 전투 재도전 상태로 돌아오는 경우도 소비 규칙이 달라지지 않아야 한다. 임의 과거 수동 저장을 어디까지 되돌릴 수 있는지 같은 전역 정책은 새로 확정하지 않는다.

회복품이 0개여도 유효 이동·저지·철수로 승리 가능한 구성을 검증한다. MP가 없거나 에일의 HP가 낮은 MQ10 저장으로 들어올 수 있음을 고려해 시작 전 실제 회복 수단을 안내하고 준비 기회를 제공한다. 전투를 시작했다는 이유로 무료 완전 회복시키지 않는다. 승리 후에도 HP·MP를 유지하고 숙소/회복의 명시적 절차를 따른다.

## 화면·입력·이벤트

B09는 현재 설정의 선택 키와 명령 UI를 표시한다. 기본 숫자 1~4 슬롯 체계에서는 빈 슬롯을 비활성으로 표시하고, 리아가 실제 들어간 슬롯을 안내한다. 인물 선택과 이동 대상 선택, 시간 재개를 서로 다른 단계로 구분한다.

E01/E02/E03은 각 조건에서 최초 1회 발생한다. 일시정지/기록 재열람으로 다시 타격·소비·승리 처리를 하지 않는다. 짧은 알림은 읽기 동안 시간이 흐르는지 여부를 통일한다. 필수 긴 설명은 정지 상태에서 보여주고, 실행 중 짧은 경고는 HUD에도 남겨 놓친 정보를 다시 볼 수 있게 한다.

위험·철수·목표는 색만으로 구분하지 않는다. 수레 도착과 전체 승리는 다른 표시로 보여준다. 고정 방향 카메라에서 에일·리아 선택 표시, 수레 경로, 철수 구역, 남은 여유와 목표가 겹치지 않는지 기준 화면과 글자 확대에서 확인한다.
