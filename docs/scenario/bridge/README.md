# MQ11~15 · 교량 구조 편 구현 인계

- MQ11: 수비대와 리아 양쪽의 현황을 듣고 제한 구조 통행 합의.
- MQ12: 반대편 수레 수리·환자 탑승·인수 담당·퇴로 준비.
- MQ13: 에일·리아 2인에게 명령하며 수송과 아군 철수를 함께 완수.
- MQ14: 도착/치료/미확인 명부와 증언 동의를 확인하고 리아 동행 의사 연결.
- MQ15: 현장 구호 인수와 자료를 준비해 왕도 외곽에 지원 요청·조사 자료 각각 접수.

32장면·193개 대사/서술/선택/안내 항목이다. 메인 19, 선택 분기 4, 전투 사건 3, SE04 개인 이벤트 3, 실패 1, 재대화 2장면으로 구성한다. 기존 리아 SE04 ‘잘린 밧줄’을 상세화했으며 본편 진행에 필수로 만들지 않았다.

레온은 귀환 편의 부상이 이어져 이 장에서도 비전투로 둔다. 이전 프롤로그 명세의 ‘교량 장 전 전투 복귀’ 제안을 조정한 이유를 인계 문서에 명시했다. 고유 적 보스·전멸 강요·교량 폭파·새 마법을 추가하지 않는다. 전투 수치와 일부 임무 실패 조건은 검토할 제작안이다.

선행은 [MQ06~10](../homecoming/README.md), 상위는 [메인·서브 시나리오](../README.md)다. 문서의 장면 원본은 런타임 스키마가 아니며 그대로 게임에 복사하지 않는다. 편집 시 원본과 대응 대본·항목 ID를 함께 갱신한다. 상위 발췌 생성 도구는 이 상세 대본을 생성하지 않는다.

현재 완료한 것은 문서다. 검수 36항목은 모두 미수행이며 게임 코드·런타임 대화·애셋을 수정하거나 게임을 실행하지 않았다.
