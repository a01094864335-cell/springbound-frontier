# 조사 결과를 제작으로 옮기는 순서

이 문서는 조사 결과의 우선순위다. 이번에 그림·동작·맵·게임을 새로 제작/실행했다는 뜻이 아니다. [전편 구현58작업](../production-plan/implementation-order.md)의 인수·아트·UI·음향 작업에 연결한다.

## 1. 첫 제작본 자료 확정 — P0

1. G01: 다른 로컬이 실제 쓰는 코드/기획/에셋 커밋 확인. main만 인수해 자료가 없다고 중복 제작하지 않는다.
2. G02~06: 에일·레온·마르타·첫 들쥐의 최종 크기·활성 클립·손/발·표정 매핑. 전편933클립을 다 끝내야 시작하는 것은 아니다.
3. G08/G42: 일반공격과 별개 범위 도약의 포즈/예고·즉시 아이템 표현·타격/효과 연결.
4. G25/G27: 집·서리골·산길·돌샘의 실제 셀/원점/가림과 출발/귀환 상태.
5. G31/32/34/43: HUD/명령/미복구 경고·기본 소리. 기존 UI/VFX/음원을 재사용해 한 번 끝까지 검수.

완료 증거는 실제 화면의 걷기/무기손/초상화·첫 전투·패배 재도전·약과 환자 인수다. ‘PNG가 있다’만으로 완료 처리하지 않는다. 이 실행 검수는 다른 로컬이 한다.

## 2. 교량 구조 세트 — P0

G10~13/G26/G28/G33. 리아 창·병사/궁병·수레/들것 조립, 수리/환자 탑승, 양안/퇴로·KO 인수와 전투 UI를 묶는다. 한 명 KO에서 살아 있는 인물 지휘→실제 경로 확보→구조 인수까지 보이고, 캐릭터가 순간이동하거나 레온이 싸워 구조하지 않게 한다.

독립적으로 그릴 새 일러스트보다 기존 수레/바퀴/들것·작업/처치 포즈를 묶는 타임라인/리깅·상태 전달물이 먼저다. 원화 보드·모션 클립·타격판정·임무 완료를 별도 승인/검수한다.

## 3. 왕도·북방·해양·성역 — P1

G07/09/14~24/G29/G35/G37/G39/G40/G41. 주요 인물 표정, 시전/복귀 포즈, 자료·동의·연락 UI, 도시 외관과 실내 세트를 지역 순서로 정합한다. 세나/카이/이리스의 기본 무장 클립은 존재하므로 전부 다시 제작하지 않는다. 선원 구조와 자료 인수는 공용 사건을 조합한다.

거대한214보드 목록 전체를 선행으로 만들지 말고 M08~M25의 필수 건물·통로·소품부터 네이티브화한다. M02의 기존 마을 생성 코드와 M13/M18의 배치 보드뿐인 후보는 같은 ‘맵 없음’으로 묶지 않는다. 원본이 있는 최저 구현부터 시작한다.

## 4. 공동 작전·중추·귀향 — P1

G16/17/G30/G36/G40/G41/G45. 거점별 준비/시작/완료/중단과 판본/시각·안전 여력 UI, 제어 상태·비출전 역할·인수·후일담을 실제 원고와 맞춘다. 새 그림이 아니라 상태/콘텐츠·연결 문제인 부분이 많다.

추가 엔딩CG·녹음음성·레온 고향 필수맵·새 최종보스는 자동 추가하지 않는다. 기본 근황과 해금한 개인 후일담을 기존 초상화+장면 배치로 먼저 완성한다.

## 5. 전편 표현·출시 검수 — P1

G03/G04/G38/G39/G44/G46. 경계 후보331개와 그 외 실제 화면에서 발견한 손/발/실루엣, 소형 아이콘, 한글 폰트/폴백,80음원 실청취/루프·믹스·Windows를 확인한다. 경계 후보는 실제 잘림 여부에 따라 수정/재패키징/유지로 판정한다. 모두 재생성하지 않는다.

## 제작 티켓에 붙일 필드

- G번호·영향 MQ/SE/맵·확정 규칙/제작안 여부
- 재사용할 기존 asset ID·고정 커밋·clip→resource→atlas/rect 또는 씬 경로
- 신규 그림/추출/조립/리깅/연결/검수 중 작업 종류
- 크기/방향/발/손/표정·소품 결합·UI 상태·타격/소비/인수 시점
- 완료 증거: 실제 화면·재생·문자확대·밝고 어두운 배경·실청취 등 필요한 항목
- 코드/에셋/문서 커밋과 미검증 항목

작업 묶음46개는 추정 외주 이미지46장이나2412개의 재제작 주문이 아니다. 같은 원본의 재사용과 단계적 최종화를 우선한다. 현재 환경에서는 조사와 인계만 완료하고 실제 게임 실행을 하지 않는다.
