## 먼저 필요한 것

1. **에일·레온·리아와 첫 적의 최종 픽셀/원점/무기손 정합** — 원본을 버리지 말고 활성 클립부터 정리. 셀 경계 후보를 우선 확인한다.
2. **주요 인물 표정별 초상화 추출·정합·매핑** — 원화 보드에 표정이 있으므로 재사용부터. 새 얼굴 전체 제작은 불필요하다.
3. **시전·아이템·부활 및 교량 들것/수레 수리 연출** — 전용 매핑이 없는 몸동작/짝동작과 사건 조립을 보완한다.
4. **맵 조립·좌표 변환·지역 상태** — 기존 필드/실내는 재사용하되 논리좌표와 실제 원점·크기·축, 우물/피난/북방/중추 전후 상태를 연결한다.
5. **전투/호위/자료/작전 UI 콘텐츠와 실제 상태** — 공용 UI36틀은 있으나 인수·철수·KO구조·미복구·판본·수신 상태는 더 필요하다.
6. **개별 도시 외관/건축 모듈 최종화** — 건물64·지역부품72·공용부품12·환경변형55·배치도11은 보드 단계. 현재 채택 공간에 필요한 것부터 네이티브화한다.
7. **장면별 효과/음원 매핑·소형 아이콘·한글 표시 검수** — 기존29효과/80음원을 우선 활용하고 모자라는 것만 추가한다.
