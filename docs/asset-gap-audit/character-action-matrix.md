## 초상화 슬롯 제작안

6주요인물 각6감정(기본/작은웃음/걱정/놀람/결의/피로), 마르타6, 발테르·실베르·네리아 각4로54개 의미 슬롯을 제안한다. 이는 **54개 새 원화나54개 누락파일이 아니다.** 보드의 기존 표정을 추출·크롭/크기/눈높이/좌우여백을 맞추고 의미에 대응시킨 뒤 실제 부족 표정만 추가한다. 셀 채색 초상화와 도트 인게임의 역할은 유지한다.

기존 프롤로그는3portrait명 보드와7NPC 보드의 고정 크롭을 사용한다. 따라서 얼굴 자체가 없는 상황은 아니다. 주요 인물의 전체 대사에서 표정 상태가 바뀌고 같은 UI에 정렬되도록 하는 전달물이 부족하다. 일반 행인에게 전원6감정 얼굴을 자동 제작하거나 음성녹음을 추가하지 않는다.
