# 외부 로컬 구현 작업 목록·의존성

58개 작업은 현재 환경에서 실행할 목록이 아니라 다른 로컬 인계 목록이다. 역할은 담당 분야이며 실제 사람/일정/자동 실행 에이전트를 지정하지 않는다. 이미 다른 로컬에서 수행한 항목은 결과 커밋과 증거를 대조한다. 미확인을 미착수/완료로 추정하지 않는다.

## 진행 순서

1. T01~T13 기준/입력/명령/아이템/실패 → T14~T20 프롤로그 기능 완주.
2. T21~T25 귀환·교량 → T26~T40 왕도/연구/해양/성역/협력.
3. T41~T49 중추/결말/개인 이벤트 → T50~T58 최종 표현·전편/Windows 검수.

T20은 기능 검수이며 미술/음향 완성 승인이 아니다. 프롤로그 연출 완료에는 해당 구간의 T50/51/57 증거도 필요하다. T58은 실제 배포·머지·출시 실행이 아니라 검토 가능한 결과 보고다.

## 인계 자료

- [기획판/제안 기준](README.md)과 [원본 작업 DAG](tasks.json).
- 선행 PR15→16→17→18 시나리오와 상태 접점. 이번 통합안은 PR18 후속이다.
- 에셋은 PR14 커밋에서 별도 인수한다. 시나리오 브랜치에 경로가 없다고 같은 초안을 다시 제작하지 않는다.
- 확정 기획·원작 Windows PC CD판 비교 미확인 항목·현행 로컬 코드와의 차이.
- 실제 영상/로그/검수 결과·미검증. 현재 환경의 게임 실행을 요청하지 않는다.

## 변경·보고 규칙

시제품 수치 변경은 사유·영향 MQ/맵/전투·저장 호환을 기록한다. 국가/무기/연애/상태이상/엔딩/배포를 자료 존재만으로 확정하지 않는다. 작업 DAG는 순서 검토용 데이터이며 외부 태스크 서비스에 자동 생성하거나 사람에게 메시지를 보내지 않았다.
