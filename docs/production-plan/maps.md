# 맵 구성·논리 격자·사건 배치

29개 플레이 공간 제작안. 29개 기존 필드 에셋과 1:1인 목록이 아니다. 실내/광장/필드를 플레이 기능으로 묶었다. 지명·크기·좌표는 최종 확정이 아니라 외부 로컬 블록아웃 검토 기준이다.

좌표는 좌하단 (0,0), X 오른쪽·Y 위쪽. 범위 40×30셀, 기본 입구 (2,15), 출구 (37,15). 주요 길은 y=15, 각 조사 지점으로는 x가 같은 세로길을 낸다. 네 방향 이동만 허용한다. 충돌·높이·카메라·최단 경로 실행 검수는 미수행이다.
