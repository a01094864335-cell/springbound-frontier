## 확정과 제안의 구분

[확정 기획](../confirmed-design.md)이 우선한다. 이번에 수치·좌표·적 수·레벨·가격·전문화 비용·개별 기술/무기 허용·회복 최저선·연락 시간 등을 검토 가능한 **제작안**으로 만들었고 사용자 확정 규칙으로 소급하지 않는다. 구현자는 제안과 현행 코드·원작 미확인 세부의 차이를 기록하고 시제품 결과로 조정한다. 현재 문서 작업이 바로 게임 코드 적용 승인을 뜻하지 않는다.

에셋은 파일 경로 존재를 확인했다.2412참조는2412고유이미지가 아니고, 1차 클립/블록아웃/도안을 최종 미술 승인·청취·게임 연결로 표시하지 않는다. 기존 에셋205개 참조만 스토리 기준 트리에 있으므로 PR14 자료를 별도로 받아야 한다. 다른 로컬의 현재 구현 상태는 미확인이다.

## 다른 로컬 시작 순서

1. 시나리오 PR15→16→17→18와 에셋 PR14, 이번 후속 기획 PR의 기준 커밋을 확인한다. 현재 브랜치는 PR18 후속이며 에셋 브랜치를 자동 합치지 않았다.
2. 수정표의 확정 규칙 충돌부터 반영하고 진행/저장·아이템·KO·재도전 계약을 맞춘다.
3. 첫 제작본의 기능→연출·미술·음향 검수를 나누어 진행하고, 귀환/교량→왕도/북방/해양/성역→중추/귀향으로 넓힌다.
4. 미상세 부분을 작업자가 임의로 덧붙이지 않도록 이번 좌표/배치/예산을 시제품 기준으로 삼고 차이를 기록한다.
5. 실제 실행·영상·플랫폼·수치/지도·저장 검증 결과를 GitHub에 남긴다. 현재 환경에 게임 실행을 요청하지 않는다.

이 패키지의 완료는6개 기획 작업과 기존 문서 보완의 완료다. 전편 게임 구현·최종 수치 승인·최종 애셋/출시 품질·플랫폼 검수·배포는 아직 완료라고 주장하지 않는다.
