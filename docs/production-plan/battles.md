# 전투 24개 배치·행동·승패·보상 제작안

[전투 데이터](encounters.json)는 위치·적 구성·초기/증원 상한·기한·목표 시간·승패 조건을 가진 문서용 데이터다. 런타임 파일이 아니고 숫자는 미승인 시제품 값이다. 4개 필수(B01/B07/B20/B24), 20개 일반 선택 교전의 첫 배치안이며 매 장 전투를 계속 추가해야 한다는 뜻이 아니다. 일반 교전은 시인성·우회·준비 기회를 제공하고 선택 교전 미완료가 메인 조건으로 들어가지 않는다.

H는 해당 장의 ‘메인만 진행한 경로’ 주인공 최대 HP를 기준으로 산정할 상대 단위다. 실제 피해 공식·방어/명중·속성은 미확정이며 이미 구현된 공식과 대조한다. 범위 예고1.2초/회수1.5초, 일반 행동 간격2초를 첫 시제품 기준으로 제안하되 시전·행동 후 대기를 재사용 대기시간과 혼동하지 않는다. 아군/적 일반 피격은 시전을 취소하지 않고 지정된 방해 기술만 취소한다. 마나는 발동 시 소비, 취소 시 미소비, 범위 아군 오폭 없음이라는 확정을 따른다.

첫 튜토리얼의 공격 명령은 반복 기본 공격이다. 첫 유효 타격 때 안내 정지로 진입해 다음 자동 타격이 P14를 건너뛰지 않게 한다. 적을 부활시키거나 HP를 몰래 되돌리는 방식은 쓰지 않는다.

## 필수 전투 판정

- **B01/MQ03/M03**: 에일1인·레온 비전투. 정지/이동/대기/범위 회피/일반 공격 완료 후 실제 격파. 회복품 사용은 선택. 패배하면 전투 전 재도전.
- **B07/MQ13/M07**: 에일·리아2인. 수레 인수+양 인물 철수/구조 인계. 전원 전투불능·수레 파괴·고지 기한 실패. 한 명만 쓰러지면 생존자가 지휘하며 부활품 또는 실제 구조 NPC 인계로 회수. 부상자에게 즉시 HP를 주지 않음.
- **B20/MQ37/M26**: 최대4인. 필수 수리조/장비 인수+퇴로+입구 점검. 수리조 위험 경고와 일시 대기, 길 확보 후 이동. 적 전멸만으로 완료 금지.
- **B24/MQ41/M29**: 최대4인. 제어 차단→현장 안정→교대/전달 시간 경과→필수 완료 보고→운용 인수. 네리아 살해/적 전멸만으로 승리하지 않음. 전투 국지 실행 시간과 세계 시간 경과를 분리하고 남은 여력 안에서만 진행.

B07/B20의180/210초는 실행 시간만 흐르는 초기 기한이다. 준비·명령·필수 설명·정지 중에는 호위/적/타이머가 함께 멈춘다. B24의180~300초는 여러 국지 교전의 목표 합계이며 수십 시간의 전령 이동을300초 안에 완료하는 설정이 아니다. 교대와 수신 장면은 같은 작전의 안전 유지 단계에서 경과 시간을 표현한다.

## 난이도·회복·보상

스토리/전술 모드는 전투 밖에서 바꾼다. 첫 시제품은 스토리 적 피해0.70·적 HP0.85·범위 예고 여유1.30·호위 기한1.30, 전술1.00을 제안한다. 보상·관계·줄거리는 동일하다. 이 보정은 확정 수치가 아니고 실행 결과로 조정한다.

생존자의 HP/MP는 종료 후 유지한다. 전투불능자는 승리 때 낮은 HP로 복귀(표본20% 최대HP), 마나는 유지한다.20%는 미확정 복귀량의 제작안이다. KO 상태로 서 있는 승리 모션을 먼저 재생하지 않는다. 전원 전투불능은 패배이며 자동 복귀는 승리 판정 뒤에만 적용한다.

실패 시 전투 전 HP/MP/위치/퀘스트/획득 보상으로 돌아가되 소비한 아이템은 복구하지 않는다. 전투 보상과 MQ 보상은 서로 다른 1회 ledger로 관리한다. 재전투·저장·로그 재열람으로 처음 보상 중복 지급 금지. 일반 교전의 반복 등장/재보상 정책은 미확정이므로 이 제작안에서는 첫 교전만 보상하고 무한 파밍을 기본 성장 전제로 두지 않는다.

배치별 세부 목록은 [전투 데이터](encounters.json), 장별 EXP/금액은 [성장·경제](growth-economy.md)를 따른다. 모든 일반 교전을 건너뛴 경로에서 필수 전투가 가능한지 외부 로컬에서 검증하고, 불가능하면 메인 보상/적 수치/구호 휴식의 기준을 고친다. 선택 전투를 사실상 필수 레벨 노가다로 만들지 않는다.
