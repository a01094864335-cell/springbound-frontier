# 기존 에셋과 전편 요구 대조

기준 에셋 커밋: `63ae017a26d036c2fba002fe79ac2393d1bcd8ee` (PR14 제작 브랜치). 시나리오 브랜치와 별개이므로 다른 로컬은 두 자료를 함께 받아 충돌을 검토한다. 이번 작업에서 에셋을 복사/새 제작/게임 연결하지 않았다.
