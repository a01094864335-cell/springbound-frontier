## 이동·시간 연표 제작안

아래 날짜는 세계 달력의 확정 연도가 아니라 인과 검토용 상대 일자다. 한 실제 플레이 초가 세계의 정확한 한 초라는 뜻이 아니다. 지도 거리·산길 속도·전령 소요를 다른 로컬에서 산정한 뒤 조정한다.

| 상대 시점 | 구간 | 시간 경과의 이유 |
|---|---|---|
| D0~1 | MQ01~05 집·산길·돌샘 | 배달·첫 전투·밤 휴식·귀환 기록 수신 |
| D2~3 | MQ06~10 귀환·피난 준비 | 생활 피해·장부·대기소 인계 |
| D4 | MQ11~14 교량 구조·야영지 | 수리·호위·명부/진술 확인 |
| D5~9 | MQ15~20 왕도 이동·체류 | 행정 열람/보전·물자 출발·진료·독립 의뢰 |
| D10~13 | MQ21~22 남방 이동·재측정 | 독립 관측과 반복 확인 |
| D14~18 | MQ23~26 북방·제한 시험·회복 | 허가·지연 관측·경고 수신·분담 |
| D19~25 | MQ27~31 항구·구조·해양국 | 항로·독립 자료·협상과 실제 수송 검증 |
| D26~34 | MQ32~36 성역·공동 준비 | 동의·현행 절차·여러 차례 전달/인수 |
| D35 이후 최대7일 창 | MQ37~41 중추 작전 | 현장 진입·수정 판본 재확인·유지/교대·완료 보고 |
| 안전 귀환 확인 뒤 | MQ42 귀향/후일담 | 길·구호·운용 인계. 출발 날짜를 무조건 고정하지 않음 |

최종 연락은 작전 권역의 필수 담당 거점이 대상이며 각국 수도 전체가 즉시 대화하는 구조가 아니다. 먼 국가의 동의·자료는 앞선 전달 주기로 이미 반영한다. 최종 권역 편도 최대24시간을 작업 가정으로 두면 수정 판본 왕복48시간, 현장 작업/완료 수신48시간, 진입24시간, 점검12시간, 예비24시간 = 156시간이다. 계측으로 확보한 가용168시간 이내에서12시간 여유가 남는 초기 산정안이다. **실제 거리/여력 검증 결과가 아니라 양립 가능성을 계산한 제안**이다. 경로가24시간을 넘거나 여력이156시간보다 짧으면 MQ36 합의 이전에 거점/보급/출발 계획을 수정한다. 기다리는 장면이 여력을 충전하지 않는다.

## 보류 항목과 반영 규칙

수치·정확한 지도 거리·가격/레벨 곡선·직업별 무장·새 초상화/동작 최종 품질은 제작안이다. 외부 로컬에서 첫 제작본과 전투 시제품 결과를 보고 조정한다. 확정 기획을 조용히 덮지 않고 변경점·사유·영향 MQ·저장 영향을 기록한다. 이번 작업으로 원작 Windows CD판의 미확인 세부 규칙을 확인했다고 주장하지 않는다.
