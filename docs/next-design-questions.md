# 다음 설계 질문
2026-10-27 · 진행 방식: 전투 규칙은 사용자가 지정할 그로우랜서 작품을 참고해 동일하게 정리하고, 원작에 없거나 기존 확정 사항과 충돌하는 부분만 한 번에 한 질문씩 확인합니다. 기존 Q04~Q13은 개별 질문 진행을 중단하고 비교 점검 목록으로 보관합니다.
기존 결정: [확정 기획](confirmed-design.md). 아래 선택지와 추천은 전부 미승인입니다.

## 확정한 질문 — Q01 아이템 연속 사용
- 사용자 선택: 2번. 아이템 효과는 즉시 발생하며, 사용한 캐릭터에게 짧은 행동 후 대기를 적용합니다.
- 구체적인 대기 시간, 시간 정지 중 처리와 시전 중 병행 사용은 미정입니다.

## 확정한 질문 — Q02 아이템 사용자
- 사용자 선택: 1번. 생존한 캐릭터 한 명을 사용자로 지정하고, 그 사용자에게 행동 후 대기를 적용합니다.
- 전투 불능자 본인은 사용할 수 없으며, 생존한 동료가 부활 아이템을 사용합니다.
- 시전 중 아이템 사용 가능 여부는 미정입니다.

## 확정한 질문 — Q03 명령 실행 방식
- 사용자 선택: 2번. 여러 동료에게 명령을 정한 뒤 별도의 재개 입력으로 시간이 다시 흐릅니다.
- 모든 동료에게 명령을 지정해야 하는지와 예약·취소 세부는 미정입니다.

## 질문 진행 현황
- 기존 전투 Q01~Q03과 추가 전투 C01~C03은 답변 완료. 기존 Q04~Q13은 개별 질문을 생략하고 원작 비교 조사로 전환했습니다.
- 추가 전투 질문: 3/3 완료.
- 제작 준비: 9개 항목 중 P01~P09 완료. 전체 12/12, 현재 계획된 질문은 0개 남습니다. P09는 Windows 출시를 기준으로 확정했으며 현재 Mac에서의 테스트 방식을 설명했습니다. 원작 전투 규칙 조사는 별도 진행 중이며 질문 완료가 구현 명세 검증 완료를 뜻하지 않습니다.
- 원작 사실 확인은 에이전트 조사 업무이며 사용자 질문 수에 포함하지 않습니다. 확인된 충돌이 생기면 질문을 추가하기 전에 이유와 개수를 알립니다.
- 상세 비교와 자료 한계: [그로우랜서 전투 검토](growlanser-combat-reference.md).

## 확정한 참고 작품
그로우랜서 1편 한국어 Windows PC CD판. PS·PSP판의 세부 규칙을 검증 없이 적용하지 않습니다.

## 확정 — C01/3: 3D 지형 높낮이의 전투 효과
사용자 선택: 1번. 첫 제작본은 높낮이를 이동·길찾기와 화면 표현에만 사용하며, 높이에 따른 사거리·명중·피해 보정은 없습니다.

## 확정 — C02/3: 적 공격 예고 표시
사용자 선택: 2번. 적의 범위 공격은 발동 전에 바닥에 위험 범위를 표시합니다. 일반 공격의 바닥 표시는 추가하지 않습니다. 표시 시간과 난이도별 반응 여유 수치는 미정입니다.

## 확정 — C03/3: 재도전 시 복원 범위
사용자 선택: 2번. 체력·마나·위치·퀘스트 진행과 획득 보상은 전투 직전으로 되돌리되, 전투 중 소비한 아이템은 돌려주지 않습니다.

## 확정 — P01/9: 프롤로그의 전투 수단
사용자 선택: 1번. 에일은 빌린 검의 일반 공격과 회복 아이템을 사용하며, 마법은 이후에 소개합니다. 레온은 기존 확정대로 첫 전투에서 부상으로 싸우지 않습니다. 이동·대기·회피 조작은 유지합니다.

## 확정 — P02/9: 캐릭터 도트 제작 기준
사용자 선택: 1번. 48×64픽셀 기본 캔버스, 4방향, 좌우 반전 활용 및 검을 든 손·비대칭 장비 보정. 필수 동작은 대기·걷기·공격·피격·전투 불능입니다. 기본 캔버스는 캐릭터별 신장·체형을 동일하게 만드는 뜻이 아닙니다.
프레임 수는 제안값이며 별도 확정하지 않았습니다. 제작 초안에서 움직임을 검증해 조정합니다.

## 확정 — P03/9: 화면 비율과 UI 크기
사용자 선택: 1번. Steam용 PC 게임, 16:9 와이드, 기준 해상도 1280×720. 창 크기에 맞춰 조정하고 UI·대사 글자 확대 설정을 제공합니다. 기준 해상도는 고정 출력 해상도가 아닙니다. 카메라 배율과 기본 글자 크기는 시안에서 검증합니다.

## 확정 — P04/9: 키보드·마우스 기본 조작
사용자 선택: 1번. WASD 탐험 이동, E 상호작용, Space 시간 정지·재개, 숫자 1~4 동료 선택. 전투 명령·대상·이동 목적지는 마우스로 지정하고 키 변경을 지원합니다.

## 확정 — P05/9: 프롤로그 맵 분리와 전환
사용자 선택: 1번. 집 내부·서리골·산길·돌샘 도착부는 별도 맵으로 나누며 출입구·지역 경계에서 짧은 암전으로 전환합니다. 전투는 각 탐험 맵에서 별도 화면 전환 없이 시작합니다.

## 확정 — P06/9: 건물 뒤 가려짐과 카메라 경계
사용자 선택: 1번. 캐릭터를 가리는 건물·나무 부분은 반투명하게 표시하며, 카메라는 맵 경계에서 멈춰 맵 밖이 보이지 않게 합니다. 반투명 대상·범위·전환 속도는 시안에서 검증합니다.

## 확정 — P07/9: 일반 전투 길이와 첫 전투 재안내
사용자 선택: 1번. 일반 전투는 약 30~60초를 밸런싱 목표로 하며 고정 제한 시간이 아닙니다. 첫 튜토리얼 전투는 안내로 더 길어질 수 있습니다. 첫 전투 패배 후 레온의 조작 안내를 선택해서 다시 볼 수 있게 하며, 긴 대사를 강제로 반복하지 않습니다. 소비 아이템을 돌려주지 않는 재도전 규칙은 유지합니다.

## 확정 — P08/9: 첫 제작본의 연출·분량·합격 기준
사용자 선택: 2번. 프롤로그 전체 텍스트 대사, 주요 인물의 표정별 초상화, 장면별 BGM·효과음을 갖추고 음성은 넣지 않습니다. 목표 플레이 시간은 약 30~45분이며 강제 분량이 아닌 검증 목표입니다. 음원은 사용 권한이 확인된 자료를 사용합니다.
합격 기준: 서리골부터 돌샘까지 진행 불가 없이 완료, 이동·대화·전투·재도전·저장/불러오기 동작, 첫 전투 안내와 레온과의 동행 이유가 이해됨.

## 확정 — P09/9: 출시 운영체제와 현재 기기 테스트
- 사용자 지정: Windows PC 기반으로 출시. 현재 기기에서 테스트할 수 있는 방법을 요청했습니다.
- 현재 기기는 arm64 macOS입니다. 같은 Godot 프로젝트를 Mac에서 실행해 전투·대화·맵·UI를 테스트하고, Windows용 빌드를 별도로 내보내는 개발 방식으로 정리합니다.
- Mac 내부 테스트 지원이 macOS 정식 출시를 의미하지 않습니다. Windows 실행 파일 자체의 검증은 Windows 환경에서 별도로 수행합니다.
- Godot 버전·렌더러·저장 경로·Steam 연동 기능의 기존 제작 제안은 개별 승인되지 않았으므로 기술 검토 대상으로 남깁니다.
- 참고: [Godot Windows 내보내기](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_windows.html), [Godot macOS 다운로드·내보내기 템플릿](https://godotengine.org/download/macos/).

## 비교 점검용 기존 질문 — Q04 이동 명령 후 행동
이동 명령으로 지정한 위치에 도착하면 어떻게 행동할까요?

1. 그 자리에서 대기하며 다음 명령을 기다립니다.
2. 이전 공격 대상이 유효하면 그 대상에 대한 기본 공격을 재개하고, 없으면 행동 방침을 따릅니다.

추천: 1번. 회피하거나 위치를 잡으려고 이동했을 때 다시 적에게 접근하는 일을 막을 수 있습니다. 이는 아직 미승인입니다. 대기 중 반격 여부는 Q06에서 확인합니다.

## 프롤로그 제작 범위를 구체화할 질문
1. 프롤로그에서 가능한 일반 공격·마법·아이템은 무엇인가? 부상 레온은 첫 전투의 명령 가능한 전투원에서 제외하는지 명시.
2. 필수 애니메이션 목록과 프레임 수, 기본 도트 크기, 4방향 좌우 반전 허용 범위는?
3. 기준 해상도·화면 비율·화면 확대·텍스트 크기는?
4. 이동·상호작용·명령·시간 재개 키와 마우스 조작, 키 변경 지원은?
5. 집 내부·마을·산길·돌샘 도착부의 맵 분리와 전환 방식은?
6. 건물 뒤 캐릭터 가려짐과 카메라 경계 처리는?
7. 일반 전투의 예상 길이와 첫 전투의 실패·재안내 방식은?
8. 첫 제작본의 대사·초상화·음향 범위, 목표 플레이 시간과 합격 기준은?
9. Steam용 PC 실행 빌드의 지원 운영체제·Godot 버전·렌더러·저장 경로와 배포 방식은? Steam 연동 기능은 첫 제작본 필요 범위를 따로 정리합니다.

## 본편 확장 전에 확인할 질문
- 무기·전문화 종류, 습득·변경 조건과 비용, 동료별 전투 역할.
- 레벨·장비·기술 성장 비중, 경험치 보정 산식.
- 상점·소지금·드롭·소지품 한도, 비싼 부활 아이템의 실제 공급량.
- 관계 단계·이벤트 개방 조건, 연애 대상과 후일담 변화.
- 챕터 전환 경고, 시기 제한 이벤트 안내, 지역별 재방문 조건.
- 최종 적대 인물·해결책의 대가·국가 갈등의 논리.
- 본편 분량·팀 규모·예산·제작 일정과 42개 메인 퀘스트의 적정성.

숫자와 비용은 플레이 검증으로 조정할 수 있습니다. 다만 플레이어가 무엇을 할 수 있는지, 명령과 시간·자원이 어떻게 연결되는지는 프로토타입 상태 설계 전에 정의해야 합니다.
