## 사용

Godot 프로젝트 `game/` 안의 `assets/production/`에 장면·음원·카탈로그가 있습니다. 기존 환경의 픽셀 재질을 참조합니다. 인테리어 장면을 인스턴스하고 `Entry`에서 캐릭터를 시작할 수 있습니다. 원점은 방 중앙 지면이며 +Z가 정면 출입구입니다. 커스텀 GridWalker는 루트의 `metadata/grid_obstacles`를 등록해야 합니다. 물리 충돌만 추가해서 그리드 충돌이 자동으로 반영되지는 않습니다.

VFX 장면은 `play()`, `stop()`, `seek(0.0~1.0)`을 제공합니다. `duration`, `loop`, `autoplay`, `free_when_finished`를 설정할 수 있습니다. 재질은 인스턴스마다 복제하며 효과는 피해·보상·상태이상 이벤트를 실행하지 않습니다. 날씨 효과는 카메라를 바라보는 제한 영역 레이어이며 전체 월드 볼륨을 대체하지 않습니다.

음원은 `assets/production/audio/audio_bank.gd`를 preload한 뒤 `stream("audio-2-02")`처럼 불러옵니다. 반환된 AudioStreamWAV에 카탈로그의 루프 지점이 적용됩니다. 효과음·음악의 재생 버스와 음량은 사용하는 게임이 정합니다. 원본은 모두 샘플 없이 합성했으며 합성음 스타일입니다. 생물 소리와 거리 활동음은 사실적인 녹음이 아닙니다.

Godot 에디터에서 `game/tests/asset_production/asset_browser.tscn`을 열고 F6으로 실행하면 151항목을 선택해 장면·효과를 확인하고 음원을 재생할 수 있습니다.

## 재현과 검증

프로젝트 루트에서 `python3 tools/build_runtime_interiors.py`, `python3 tools/build_runtime_vfx.py`, `python3 tools/build_runtime_audio.py`로 생성 파일을 재현합니다. 음원은 인자로 ID를 지정해 일부만 재생성할 수 있습니다. 제작 대장은 `python3 tools/build_asset_registry.py`로 갱신합니다.

Godot으로 `game/`을 한 번 import한 후 `--headless --path game --script tests/asset_production/verify_interiors.gd`를 실행합니다. 같은 폴더의 `verify_vfx.gd`와 `verify_audio.gd`로 각각 효과와 음원을 검사합니다. 실제 렌더러에서는 `render_interiors.gd`와 `render_vfx.gd`로 화면을 저장할 수 있습니다. 검증 결과는 [검증 기록](asset-production-2026-11-02/verification.json), [VFX 기록](asset-production-2026-11-02/vfx-verification.json), [음원 로드 기록](asset-production-2026-11-02/audio-verification.json), [음원 신호 기록](asset-production-2026-11-02/audio-signal-verification.json)에 있습니다.
