# 로컬 그로우랜서 확인과 전투 개선

2026-11-06. PR #21의 MQ01~05 구현 위에서 작업했다.

## 원본 파일에서 확인한 사실

사용자가 지정한 `games/growlanser/image.img`를 Finder에서 로컬 유지하도록 다운로드했다. 파일 크기 2,200,633,856바이트, 실제 헤더/파일 읽기와 `dataless` 해제를 확인했다. 원본을 수정하지 않고 별도의 읽기 전용 APFS 복사본으로 조사했다.

- MBR의 FAT32 파티션: LBA 63, 4,298,049섹터. 루트는 `Grow`, `GAME.LNK`이며 파일 28,326개를 열거했다.
- `/Grow/Grow.exe`: 1,269,806바이트, SHA-256 `c6a95c17238718281ec317bc69bd99a0a11e639fc91d695c0e8446295ee7c8ef`. PE x86 실행 파일이다.
- 실행 파일의 실제 import에 `DirectInputCreateA`, `GetAsyncKeyState`, `timeGetTime`, `DirectDrawCreateEx`, DirectSound가 있다. 이것만으로 명령 키 배치나 전투 시간 규칙을 입증할 수는 없다.
- `/Grow/FONT/*.c` 및 `/Grow/SYS/MENU/T_MSDT.C/.H` 등 C/H 파일 15개가 있다. 확인한 `System.c`, `Sys_mes.c`, `Tm_magic.c`, `T_MSDT.C`는 문자열/글리프 인덱스와 그림의 숫자 배열이다. 전체 게임 소스나 전투 알고리즘을 확보했다는 뜻은 아니다.
- `T_MSDT.H`의 Shift-JIS 주석과 `DTNO_MGSK_HELP` 정의는 마법/스킬 도움말용 메뉴 그림이 있음을 확인해 준다. `MENUDATA.BIN`은 2,406,400바이트의 데이터다. 실행 파일에서 단순 CP949 키워드 검색으로 전투 명령을 복원하지 못했다.
- 동봉 설정은 `W95KR_Daum_Final` 런처와 별도 Win9X 환경을 참조한다. 게임 디스크 자체에는 Windows 시스템이 없다. 원본 게임의 실제 실행/전투 재현은 아직 검증하지 않았다.

원본 실행 파일·테이블·이미지·음원을 프로젝트나 Git에 복사하지 않았다. 분석용 복사본과 파일 목록은 로컬 `combat-work/tools/reference/inspection`에 보관했다.

## 이번 구현의 범위

아래는 사용자에게 불편했던 조작을 줄이는 우리 게임의 개선안이다. 원본 바이너리에서 검증한 정확한 규칙이나 수치라고 주장하지 않는다.

- 적 클릭 또는 A: 추적과 반복 공격을 바로 시작한다. 공격마다 Space를 다시 누르지 않는다.
- 우클릭: 즉시 이동 명령. 이동 버튼의 위치 선택만 잠시 멈추며, 선택 완료/취소 후 이전 실행 상태로 돌아간다.
- Space: 명시적 전술 정지/재개. 수동 정지 중 새 명령을 내려도 정지는 유지한다. 포커스 상실도 안전하게 정지한다.
- 강제 6단계 안내를 닫을 수 있는 상황별 안내로 바꿨다. 전투가 안내 때문에 멈추지 않는다.
- 공격 준비/회복과 적 행동을 막대로 표시하고 실제 명중 때 피해 숫자·명중 반응을 보여 준다.
- 공격 준비 0.24초, 공격 후 회복 0.86초, 사거리 1.48은 이번 프로토타입의 조정값이다. 회복 중에도 추적 이동한다. 인접 대각선과 이동 중 유효 거리에서도 명중한다. 지형 선 검사와 격자 기반 경로는 유지한다.
- 도약 예고는 1.25초, 착지 후 회복은 2.2초다. 별도 피해 보너스나 스킬을 만들지 않았다. 일반 물기에는 바닥 예고를 넣지 않았다.
- 부상 레온은 비전투 인물이며, 소비품 사용/재도전 기록과 MQ01~05 저장 흐름은 계속 적용한다.

이전 문서의 강제 안내 순서와 명령마다 정지하는 조작은 사용자의 최신 전투 개선 요청에 따라 변경했다. 다인 파티 명령, 원본 마법/시전/자동 반격 재현, 자유 경로 이동, 원본 실기 시간 측정은 이번 완료 범위가 아니다.

## 검증

Godot 4.6.3 / macOS arm64.

- `python3 tools/verify_prologue.py --engine <Godot> --output <결과 폴더>`: 기본 10검사 모두 통과. 전투 코어, 저장 계약, 통합, 전체 귀향 A/B 경로 포함.
- 실제 Godot 창 `tests/combat_flow_test.gd`: 20개 입력 검사 통과. 클릭 후 첫 명중 0.65초, 명령의 실행/정지 유지, 이동 선택 취소, 회복약 1회 소비, 안내 닫기, 행동 막대를 확인했다. 입력 검사는 네이티브 창용이다.
- 실제 창 `tests/prologue_e2e.gd`: A 경로 전체 완주. 승리 HP 32/48, 회복약 2개, 반복 재개 키 없이 진행. 저장값/인벤토리/승리 상태를 강제로 대입하지 않는다.
- E2E는 자동 시나리오 검증이다. 독립 사용자의 재미 평가나 원본 게임 실기 비교를 대신하지 않는다.

재현용 검사는 `tools/verify_prologue.py --native`로 함께 실행할 수 있다. 최신 원본 실행 환경이 확보되면 원본에서 직접 확인한 조작/시간 규칙을 별도로 기록하고 비교해야 한다.
