# 전투 장비 권한·모션 제작 기획

2026-10-29 · 사용자 신규 지시 반영 · **1차 대상: 에일**

이 문서는 장착 규칙과 전투·승리 모션의 제작 범위를 정의합니다. 전체 캐릭터의 애니메이션이나 전투 시스템이 완성됐다는 뜻은 아닙니다. 이번 변경에는 에일의 무기별 키포즈 시안만 포함하며 게임 코드는 변경하지 않습니다.

## 1. 새로 확정된 규칙

1. **에일은 모든 무기를 선택해 사용할 수 있습니다.** 현재 외형 분류는 한손검·창·활·단검·지팡이 5계열이며 향후 추가 계열도 에일의 장착 허용 범위에 포함합니다. 아직 없는 무기를 구현 완료로 집계하지 않습니다.
2. **에일 외 다른 전투 캐릭터는 직업 영향 범위의 무기만 장착**합니다. 캐릭터별 허용 목록을 데이터로 관리합니다. 동료뿐 아니라 전투 NPC에도 같은 원칙을 적용하되 정확한 목록은 개별 설계합니다.
3. **방어구·장신구는 캐릭터 공용**입니다. 성별·직업 때문에 장착을 금지하지 않습니다. 장비 슬롯 수·수치·중량·외형 교체 기능은 이 지시로 확정되지 않습니다.
4. 전투 가능한 캐릭터에게 전투 자세·해당 무기 동작·캐릭터성에 맞는 승리 모션을 마련합니다. **지금은 에일을 먼저 제작**하고 나머지는 후속 범위로 둡니다.

### 기존 전문화 규칙과의 관계

거점에서 전문화를 바꿀 수 있다는 기존 기획을 유지합니다. 다만 에일의 전문화는 다른 무기 장착을 막는 잠금으로 사용하지 않습니다. 숙련·기술·성장 보너스와의 연결은 별도 설계입니다. 모든 무기를 장착할 수 있다는 말은 모든 기술·마법을 처음부터 습득한다는 뜻이 아닙니다.

프롤로그는 이야기상 레온의 검을 빌려 첫 전투를 치릅니다. 처음부터 5개 무기를 지급하거나 마법을 가르치는 것으로 범위를 늘리지 않습니다. 전투 중 장비 변경 가능 여부도 아직 미정입니다.

| 에일 | 모든 무기, 현재 5계열 | 사용자 확정 | 1차 전부 |
| 레온 | 한손검 중심 | 직업 기반 제안. 정확한 확장 목록은 미정 | 에일 한손검 검증 후 |
| 리아 | 창 중심 | 직업 기반 제안 | 레온 다음 |
| 세나 | 지팡이 중심 | 직업 기반 제안 | 후속 |
| 카이 | 단검 중심, 활은 후보 | 활 허용은 미승인. 원거리 보조 역할만으로 활을 확정하지 않음 | 후속 |
| 이리스 | 지팡이 중심 | 직업 기반 제안 | 후속 |
| 마르타·일반 주민·상인 | 전투 참여 미정/범위 밖 | 무기 전체나 전투 모션을 자동 부여하지 않음 | 필요 시 별도 |
| 병사·적대 NPC | 해당 병종별 허용 무기 | 공통 보드의 무기가 자동으로 모든 개체에 확정되는 것은 아님 | 실제 전투 등장 확정 후 |

비주인공의 **직업 제한 원칙**은 확정이지만 위 개별 무기 목록은 기획 제안입니다. 검토 전에는 장착 데이터의 확정값으로 넣지 않습니다. 무기의 보유·장착·기술 사용·전투 참가 권한을 별도 개념으로 관리합니다.

## 3. 에일 공통 전투 동작 목록

| 클립 제안 | 목적 | 반복 여부·제작 기준 |
|---|---|---|
| combat_idle | 무기를 든 전투 대기 | 반복. 호흡은 작게, 발 접지 유지 |
| combat_move | 이동·접근·회피 지점 이동 | 반복. 화면 상하좌우 한 칸 이동 규칙 유지 |
| attack_prepare | 공격 준비 | 1회. 무기별 무게 중심과 준비를 읽을 수 있게 |
| attack_contact | 실제 공격 | 1회. 타격/발사 이벤트 위치를 별도 지정 |
| attack_recover | 공격 회수·자세 복귀 | 1회. 애니메이션과 행동 후 대기 시간은 별도 데이터 |
| hit | 피격 | 1회. 짧고 읽히게; 일반 피격이 모든 행동을 무조건 취소하지 않음 |
| down | 전투 불능 | 진입 후 마지막 포즈 유지 |

| victory_enter / loop / exit | 승리 후 정리·안부 확인·종료 | 1회 또는 짧은 유지. 피해 판정 없음 |
| equip_visual | 무기 시각 변경 | 실제 장착 허용과 전투 중 교체 규칙 확정 후 연결 |

프레임 수·재생 속도는 아직 최종 확정하지 않습니다. 키포즈를 승인한 뒤 움직임을 실제 크기에서 검증하여 정합니다. 장면 대사를 재생한다고 아이템 소비나 공격 판정을 다시 실행하지 않습니다.

## 4. 에일 무기별 동작 방향

| 무기 | 전투 자세 | 기본 공격의 흐름 | 회수·주의 |
|---|---|---|---|
| 한손검 | 검끝을 낮게 전방에 두고 빈손으로 균형 | 짧은 준비 → 대각선 베기 → 안전한 방향으로 검끝 회수 | 검 단독 자세 유지. 방패 조합은 [별도 추가 기획](shield-loadouts.md), 쌍검은 미정 |
| 창 | 두 손으로 축을 잡고 전후 간격 확보 | 뒤로 당김 → 직선 찌르기 → 같은 축으로 회수 | 긴 무기가 셀 밖에서 잘리지 않도록 여백 필요 |
| 활 | 왼손 활·오른손 시위, 목표 방향에 몸 정렬 | 화살 준비 → 당김 → 발사 → 활 내려 안정 | 좌우 반전 시 손·시위·화살 방향 보정; 화살 소모제는 미정 |
| 단검 | 짧은 전방 그립, 낮은 무게 중심 | 짧은 접근·준비 → 작은 베기 → 빠른 자세 복귀 | 공중 회전·무기 던지기·자동 2연타를 추가하지 않음 |
| 지팡이 | 두 손 대각선 방어 자세 | 짧은 준비 → 전방 물리 타격 → 세워 회수(가로 스윙은 대안) | 기본 물리 공격과 마법 시전은 별도 동작 |

시전·마법 전체는 이 시안에 포함하지 않습니다. 지팡이를 장착했다고 프롤로그에서 마법이 열리지 않습니다. 큰 이펙트로 읽히지 않는 타격을 숨기지 말고 실루엣부터 검토합니다.

## 5. 승리 세리머니 — 에일

### 성격 기준

밝고 다정하며 작은 농담을 하지만 힘든 상태를 숨기고 무리하는 사람입니다. 승리 후에는 적을 조롱하거나 무기를 과시하기보다 **안전하게 무기를 내림 → 숨을 고름 → 동료에게 시선과 작은 미소**가 어울립니다.

| 무기 | 무기 정리 | 안도 동작 | 동료 확인 |
|---|---|---|---|
| 한손검 | 검끝을 사람 없는 방향 아래로 | 짧게 숨을 내쉬고 손을 가슴 근처에 | ‘다들 괜찮아?’라는 인상의 작은 미소 |
| 창 | 창끝을 위로, 자루 끝을 조용히 지면에 | 어깨 힘을 풀음 | 고개를 돌려 안부 확인 |
| 활 | 화살을 걸지 않은 채 활을 내림 | 시위 잡던 손을 이완 | 주위를 살핀 뒤 안심한 미소 |
| 단검 | 칼끝을 안전한 쪽으로 내림 | 긴장을 풀고 짧게 숨 고름 | 동료 쪽 시선, 손의 힘 풀기 |
| 지팡이 | 지팡이를 세워 가볍게 지지 | 상체 힘을 풀음 | 동료와 눈 맞추는 미소 |

### 첫 전투의 예외

레온을 구한 첫 전투는 축하 동작을 길게 하지 않습니다. 손이 떨리고 경계가 풀리지 않다가 레온의 ‘끝났어’를 듣고 검을 내립니다. 레온의 상태를 확인하고 붕대 처치를 마무리하는 사건으로 연결합니다. 일반 승리 모션은 이후의 기본안이며 첫 전투를 숙련된 영웅의 세리머니로 바꾸지 않습니다.

승리 확정 후에만 재생하며 적 처치마다 실행하지 않습니다. 전투 불능 인물에게 서 있는 승리 모션을 실행하지 않습니다. 전투 종료·자동 복귀·보상·사건 진행의 순서와 연출 생략 규칙은 런타임 연결 전에 결정합니다. 연출을 넘겨도 보상이 중복되거나 누락되면 안 됩니다.

## 6. 키포즈 시안과 실제 게임 애셋의 구분

이번 1차 산출물은 무기별 12개 포즈를 배치한 **비교 시트 5장**입니다. 앞·옆·뒤 전투 자세, 옆 방향 공격 준비/타격/회수, 피격·전투 불능, 승리 3단계를 봅니다. 게임용 모든 방향·모든 중간 프레임이 만들어졌다는 뜻이 아닙니다.

다음 제작 순서는 다음과 같습니다.

1. 실루엣·무기 그립·공격 방향·캐릭터성을 검토하고 키포즈 수정.
2. 에일 신체 기준과 무기 소켓을 고정하고 투명 개별 프레임 제작.
3. 상하좌우 4방향으로 확장. 좌우를 반전할 경우 주무기 손·가방·비대칭 장비를 보정.
4. 준비→타격→회수의 중간 프레임·프레임 지속시간·클립 전이 제작.
5. 발 기준점, 키·머리 크기, 무기 끝·망토·가방의 움직임 확인.
6. 실제 Godot 전투에서 타격·발사·아이템 이벤트와 연결하고 재생·중단·반복 검수.

몸체의 48×64 기본 캔버스를 유지하되 긴 창·검·지팡이까지 강제로 그 안에 축소하지 않습니다. 무기 오버레이 또는 넓은 프레임을 검토하고 **같은 발 원점과 캐릭터 실제 크기**를 유지합니다. 최종 레이어 방식·프레임 규격·이벤트 프레임은 미정입니다. 무기 변형 25개를 모두 다른 신체 애니메이션으로 만드는 대신 계열별 동작과 장비 외형 데이터를 분리하는 안을 검토합니다.

## 7. 검수 기준

- [ ] 에일의 머리·체형·옷·가방이 기존 보드와 일치함.
- [ ] 무기별 그립과 실제 공격 방향이 맞고 무기가 다른 계열로 바뀌지 않음.
- [ ] 정지 포즈를 흔드는 대신 팔다리·몸통이 동작에 맞게 움직임.
- [ ] 몸 크기와 발 접지 유지, 무기·망토 잘림 없음.
- [ ] 4방향의 손·무기·화살·장비 위치 일관성.
- [ ] 모션 길이를 피해·행동 후 대기·아이템 효과 타이밍과 혼동하지 않음.
- [ ] 정지·재개·명령 변경·피격·다운 후 전이에서 이벤트 중복 없음.
- [ ] 일반 승리와 첫 전투의 안도·레온 확인 장면을 구분함.
- [ ] 에일의 자유 장착, 동료의 허용 목록, 공용 방어구·장신구를 검증함.
- [ ] 화면에서 재생한 증거 없이 ‘게임용 애니메이션 완료’라고 표시하지 않음.

## 후속 범위

에일의 한손검을 프롤로그에 연결해 검증한 다음 창·활·단검·지팡이로 확장합니다. 다른 캐릭터는 직업 무기 목록과 승리 성격안을 먼저 검토합니다. 예를 들어 레온은 주변 안전 확인, 리아는 짧은 자신감, 세나는 관측 확인, 카이는 가벼운 안도, 이리스는 동료 상태 확인을 후보로 두되 아직 개별 세리머니를 확정·제작한 것은 아닙니다.
