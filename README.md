# 봄을 기다리는 국경

Springbound Frontier · 가제

동료와의 관계와 탄탄한 이야기를 중심에 둔 판타지 RPG 기획입니다. 현재는 구현 전 기획 단계입니다.

## 작업자 시작 문서

[구현 전 확정한 게임 기획](docs/confirmed-design.md)

2026-10-27까지의 질의응답에서 확정한 조작·전투·성장·탐험·관계·제작 범위를 정리했습니다. 미정 사항을 분리했으며, 엔진과 첫 테스트 배포 방식은 아직 결정하지 않았습니다.

첫 제작본은 서리골의 아침부터 레온과의 첫 전투를 거쳐 돌샘에 도착하는 프롤로그 전체입니다.

## 저장소 수록 범위

현재 업로드한 내용은 작업용 결정 문서와 이 안내문입니다. 과거 대화 원문과 이미지 시안 6장, 기존 상세 시나리오는 이 저장소에 아직 업로드되지 않았습니다. 기존 로컬 묶음에 자료가 있다는 사실과 원격 업로드 완료 여부를 구분합니다.
