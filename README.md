# 봄을 기다리는 국경

Springbound Frontier · 가제

동료와의 관계와 탄탄한 이야기를 중심에 둔 판타지 RPG 기획입니다. 캐릭터 기획과 시각 보드를 바탕으로, Godot에서 프롤로그의 첫 이동 빌드를 구현했습니다. 전투·최종 배경 아트·음향은 후속 작업입니다.

## 프롤로그 플레이

현재 Mac에서 `프롤로그 플레이.command`를 실행하거나, Godot 4.6.3으로 `game/project.godot`를 열어 실행합니다.

집에서 약을 챙겨 서리골 → 산길 → 돌샘까지 이동할 수 있습니다. WASD 이동 · E 대화/조사 · 우클릭 목적지 이동 · Esc 메뉴 · F5 저장 · F9 불러오기.

## 저장소 수록 범위

확정 기획 문서와 각 유형의 최신 이미지 시안 4장을 수록합니다. 월드맵의 미수정 경로는 이미지 안내문에 정정했습니다. 이전 이미지 버전, 과거 대화 원문과 상세 시나리오는 포함하지 않습니다.

[그로우랜서 전투 참고 및 검증 현황](docs/growlanser-combat-reference.md)

출시 목표는 Steam용 Windows PC 게임입니다. 개발 중 현재 Mac에서 같은 프로젝트를 실행해 플레이 테스트하며, Windows 빌드는 별도 검증합니다. 기존 웹 우선 테스트 계획은 필수 기준에서 제외하며, 첫 테스트는 데스크톱 실행 빌드를 기준으로 준비합니다.
